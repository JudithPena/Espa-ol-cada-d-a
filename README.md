# Español cada día 🇪🇸

Telegram-бот, который каждый день публикует в канал учебный пост по испанскому языку — **с полного нуля до уровня A1**. Маленькими шагами, с постепенным погружением, повторениями и тестами.

**Превью всех постов:** `python -m espanol export` → откройте `preview/index.html` в браузере.

## Что внутри

| | |
|---|---|
| Постов | 157 (≈ 5 месяцев по посту в день) |
| Тем | 24: от алфавита до прошедшего времени |
| Слов и выражений | 615 (≈ 1600 словоформ) |
| Новых слов за пост | не больше 8 — проверяется автоматически |
| Озвучка | нейроголоса Испании (мужские и женские), бесплатно |

Типы постов чередуются: 📚 лексика · 📐 грамматика · 💬 диалог · 🎧 аудирование · 📖 чтение · ✍️ практика · 🧠 тест · 🔁 повторение.

### Программа

**A0:** 0. Старт и произношение · 1. Приветствия · 2. Знакомство · 3. Язык занятий · 4. Числа и возраст · 5. Страны и языки · 6. Вещи (род, артикли, множественное число) · 7. Профессии (глаголы на -ar) · 8. Семья

**A1:** 9. Описание людей · 10. Дом (estar, hay) · 11. Ser и estar · 12. Город (ir, транспорт, дорога) · 13. Еда (-er/-ir, в кафе) · 14. Хобби (gustar) · 15. Время и дни · 16. Мой день (возвратные и отклоняющиеся глаголы) · 17. Покупки · 18. Погода и даты · 19. Планы (ir a + инф., tener que) · 20. Здоровье · 21. Прямо сейчас (estar + герундий) · 22. Pretérito perfecto · 23. Финал и итоговый тест

## Методика

- **Только пройденные слова.** В каждом посте — только слова, которые уже были введены (или вводятся в этом же посте). Это проверяет программа: она знает формы слов (множественное число, спряжения) и «открывает» их только после соответствующей грамматической темы. Опечатки вроде латинской буквы в русском слове тоже ловятся.
- **Маленькие шаги.** Не больше 4–8 новых слов за пост, грамматика — по одной теме.
- **Постепенное погружение.** Сначала всё объясняется по-русски. После урока «Язык занятий» подписи и задания сами переключаются на испанский (*Escucha y repite*, *Traducción*, *Repaso*, *Tarea*), на уровне A1 — и заголовки (*Lección 60 · Tema 9 · Vocabulario*). Вопросы к текстам постепенно переходят на испанский. Переключение срабатывает автоматически, когда нужные слова пройдены.
- **Интервальные повторения.** Каждое слово возвращается через 1, 3, 7, 14, 30… постов: в блоке «Вспомним» в каждом посте, в постах-повторениях и в автоматических викторинах. Если слово само встретилось в новом тексте — это засчитывается как повторение.
- **Активное припоминание.** Ответы и переводы спрятаны под спойлер: сначала вспомнить, потом проверить. Telegram открывает все спойлеры сообщения одним нажатием, поэтому каждая рубрика со скрытыми ответами («Проверьте себя», «Вспомним», перевод диалога) приходит отдельным сообщением. Тесты — нативные викторины Telegram.
- **Понятный ввод (i+1).** Диалоги и тексты собраны из знакомых слов, новые слова даются перед текстом.
- **Грамматика через наблюдение.** Сначала примеры и вопрос «что вы заметили?», потом правило.
- **Лексические блоки.** Частые фразы учатся целиком: *me llamo*, *¿qué tal?*, *me gusta*.
- **Коммуникативный подход.** Каждая тема — реальная ситуация (кафе, магазин, врач) с целями «что вы сможете сделать».
- **Вывод речи.** Задания для комментариев: представиться, описать семью, рассказать о дне.
- **Слушание и проговаривание.** Аудио к словам, диалогам и текстам, паузы для повторения за диктором.

Вариант языка — испанский Испании, отличия Латинской Америки отмечены 🌎.

## Как запустить

### 1. Бот и канал

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` и получите **токен** вида `123456789:AA...`.
2. Создайте канал (можно приватный) и добавьте бота в **администраторы** с правом публиковать сообщения.
3. `TELEGRAM_CHAT_ID` — это `@username` публичного канала или числовой id вида `-100...` (его покажет, например, бот @getidsbot, если переслать ему пост из канала).

Чтобы читатели могли писать в комментариях (многие задания предлагают это), привяжите к каналу группу для обсуждений: «Настройки канала → Обсуждение».

### 2. Публикация по расписанию через GitHub Actions (без сервера)

1. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_CHAT_ID` — канал.
2. Необязательно, на вкладке **Variables**: `TIMEZONE` (по умолчанию `Europe/Moscow`), `POSTS_PER_DAY` (в workflow по умолчанию 2), `ENABLE_AUDIO` (1).
3. **Actions → «Публикация урока» → Run workflow** — первый пост выйдет сразу. Флажок «dry_run» покажет пост в логе без отправки.
4. Дальше бот публикует по два поста в день: запуски в 06:00 и 12:00 по Киеву, но GitHub обычно опаздывает на несколько часов. Время меняется в `.github/workflows/publish.yml` (строка `cron`, часы в UTC).

Прогресс хранится в `state/state.json`, workflow сам коммитит его после публикации. Если отправка оборвалась на середине, следующий запуск продолжит с того же сообщения без дублей.

> ⚠️ Расписание GitHub запускает только в ветке по умолчанию (обычно `main`). Если ветка с ботом другая — слейте её в `main` или сделайте её веткой по умолчанию.
> GitHub может задерживать запуск по расписанию на несколько часов (у этого бота бывало 5–9 часов), поэтому время в `cron` стоит ставить с запасом.

Хотите один пост в день — оставьте одну строку `cron` и поставьте переменную `POSTS_PER_DAY=1`.

### 3. Или на своём компьютере / сервере

```bash
pip install -r requirements.txt
cp .env.example .env           # впишите токен и канал
python -m espanol check        # проверит токен и права бота в канале
python -m espanol publish      # опубликовать следующий урок
python -m espanol run --at 09:00            # постоянный режим: каждый день в 09:00
python -m espanol run --at 09:00 --at 19:00 # два поста в день (POSTS_PER_DAY=2)
```

Или через cron: `0 9 * * * cd /путь/к/боту && python3 -m espanol publish`.

### 4. Посты-статьи

С лета 2026 года Telegram умеет публиковать посты-статьи (Rich Messages): текст с заголовками, картинками, таблицами и аудиоплеерами внутри одного поста. Бот умеет собирать урок в таком виде:

- **обложка урока и карточки новых слов** рисуются автоматически в стиле аватарки канала;
- **аудио стоит прямо под словами и под каждым диалогом**;
- **ответы и переводы спрятаны в раскрывающиеся блоки**, и каждый открывается отдельно;
- опросы, как и раньше, приходят отдельными сообщениями после статьи.

Какие уроки уходят в канал статьёй, задаёт настройка `rich_posts` в `content/course.yaml`: список id уроков или `all` для всех (сейчас `all`). Остальные публикуются в обычном формате. Посмотреть любой урок в новом виде можно у себя в личке:

1. Напишите боту любое сообщение, например `/start`.
2. **Actions → «Тест урока в личку» → Run workflow**, укажите номер урока.

Урок придёт в личный чат того, кто последним написал боту; в канал ничего не уходит, прогресс не меняется. Локально: `python -m espanol preview 8 --rich` и `python -m espanol send 8 --rich --chat auto`.

## Команды

| Команда | Что делает |
|---|---|
| `python -m espanol validate` | проверяет весь курс: незнакомые слова, лимиты Telegram, разметку, «маленькие шаги» |
| `python -m espanol stats` | статистика по темам и словам |
| `python -m espanol preview 12` | показывает урок №12 (вводный урок — №0) так, как он уйдёт в канал (`--html` — исходный HTML) |
| `python -m espanol export` | HTML-превью всего курса в `preview/index.html` |
| `python -m espanol lookup hablamos` | в каком уроке слово впервые появляется |
| `python -m espanol status` | сколько опубликовано и что следующее |
| `python -m espanol publish [--dry-run] [--force]` | опубликовать следующий урок |
| `python -m espanol send 12 --chat 123456789` | отправить урок №12 в любой чат — например, себе в личку (ваш id покажет @userinfobot; сначала напишите своему боту /start) |
| `python -m espanol send 8 --rich --chat auto` | отправить урок постом-статьёй в личку тому, кто последним написал боту |
| `python -m espanol check` | проверить токен и права бота |

## Как редактировать курс

Контент лежит в `content/units/NN_тема.yaml`, по файлу на тему. Урок выглядит так:

```yaml
- id: vocab1             # уникален внутри темы, не меняйте после публикации
  kind: vocab            # vocab, grammar, dialogue, listening, reading, practice, quiz, review…
  title: Привет и пока
  vocab:                 # новые слова: эмодзи, слово, [произношение] — перевод :: пример — перевод
    - "☀️ buenos días [буэ́нос ди́ас] — доброе утро :: ¡Buenos días, María! — Доброе утро, Мария!"
    - "🦒 alto/a — высокий"                       # прилагательное: формы alto, alta (+ altos, altas)
    - "🤲 tener — иметь {forms: tengo tienes tiene}" # явные формы, если правило ещё не пройдено
  blocks:
    - "Текст с **жирным**, _курсивом_, ||спойлером|| и `кодом` (код не проверяется)"
    - rule: "Правило в рамке"
    - examples: ["Hola, Ana. — Привет, Ана."]
    - exercise: {title: Traduce, items: ["Я из России. => Soy de Rusia."]}
    - dialogue: ["Ana: ¡Hola! | Привет!", "Pablo: ¿Qué tal? | Как дела?"]
    - reading: {title: Mi casa, text: "...", translation: "..."}
    - conjugation: {verb: hablar, ru: говорить}  # таблица спряжения строится сама
  quiz:                  # викторины Telegram; первый вариант — правильный, порядок перемешается
    - q: Как сказать «до завтра»?
      options: "¡Hasta mañana! | ¡Hasta luego! | ¡Buenas noches!"
      explain: Пояснение после ответа
```

Ещё поля урока: `unlocks` — грамматическая тема, после которой бот «знает» производные формы (`plural`, `present_ar`, `present_er_ir`, `present_stem`, `reflexive`, `gerund`, `participle`); `forms` — отдельные формы, введённые в уроке; `audio: false` — отключить озвучку.

После правок запустите `python -m espanol validate` — он подскажет, если вы использовали слово раньше, чем оно введено. Имена людей и географические названия разрешены в `content/course.yaml`.

## Структура проекта

```
espanol/            код бота
  course.py         загрузка курса из YAML
  morphology.py     испанская морфология: множественное число, спряжения, герундий, причастия
  lexicon.py        какие формы известны к каждому уроку; проверка «только пройденные слова»
  srs.py            расписание интервальных повторений
  quizgen.py        автоматические викторины по лексике
  render.py         сборка поста: HTML для Telegram, аудио, опросы, испанские подписи
  rich.py           тот же урок одним постом-статьёй (Rich Messages)
  cards.py          картинки для статей: обложка и карточки слов (шрифты в assets/fonts, лицензия OFL)
  telegram.py       клиент Bot API с повторами при ошибках
  tts.py            озвучка (edge-tts)
  publisher.py      публикация с сохранением прогресса
  scheduler.py      постоянный режим по расписанию
  export.py         HTML-превью курса
content/            курс: course.yaml и темы
state/state.json    прогресс публикации
tests/              тесты: pytest
```

Тесты: `pip install pytest && pytest -q`. Проверка курса и тесты запускаются в GitHub Actions при каждом пуше.
