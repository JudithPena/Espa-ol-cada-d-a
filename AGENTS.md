# Инструкции для агентов

Общие правила проекта находятся в [CLAUDE.md](CLAUDE.md). Соблюдай их, включая сохранность секретов и прогресса, обновление рабочей ветки и обязательные проверки перед коммитом.

Специализированные инструкции выбирай по смыслу задачи согласно разделу «Маршрутизация инструкций» в [CLAUDE.md](CLAUDE.md), в том числе при работе с общими компонентами сайта.

## Отдельный раздел грамматики

При работе с интерактивным разделом испанской грамматики применяй [content/grammar/AGENTS.md](content/grammar/AGENTS.md). Эти инструкции относятся также к задачам грамматики в общих компонентах (`espanol/grammar_player.js`, `espanol/site_template.html`, загрузчике, тестах и документации), а не только к файлам юнитов.

Полный стандарт качества — [CODEX_GUIDE_SPANISH_GRAMMAR.md](content/grammar/CODEX_GUIDE_SPANISH_GRAMMAR.md). Для создания или существенной переработки одного юнита прочитай его целиком. Шаблон задания на следующий юнит — [START_CODEX_NEXT_UNIT.md](content/grammar/START_CODEX_NEXT_UNIT.md); номер целевого юнита задаёт пользователь.

Область этих дополнительных правил — самостоятельный раздел грамматики (количество юнитов определяется текущими файлами курса). Не распространяй их на основной курс A0/A1 и другие разделы без запроса пользователя. Размещение инструкций само по себе не является заданием на переработку юнитов или изменение существующего оценивания.
