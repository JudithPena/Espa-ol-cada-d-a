# Инструкции Codex — раздел испанской грамматики

Область действия: только отдельный раздел сайта «Грамматика испанского языка» (количество юнитов определяется содержимым каталога). Не распространять задачи на основной курс A0/A1 без явного запроса пользователя.

## Постоянные правила

1. Для **нового юнита по странице учебника** прочитай целиком и применяй `docs/grammar/GRAMMAR_UNIT_GUIDE.md`: порядок работы от реестра источника до отчёта, требования к теории и упражнениям, действующий формат данных, режим ударений, проверки, шаблоны. Для существенной переработки существующего юнита **прочитай и применяй** `CODEX_GUIDE_SPANISH_GRAMMAR.md` в этой же папке и раздел 21 гайда переноса. Для небольших исправлений не требуется перечитывать весь гайд, если соответствующее правило уже понятно.
2. Работай **строго по одному целевому юниту**; сначала аудит и план, затем реализация, тесты, отчёт. Не переходи к следующему юниту без команды пользователя.
3. Не перерабатывай содержимое других юнитов массово. Общие компоненты можно исправлять с обеспечением обратной совместимости и регрессионными тестами.
4. Грамматическая точность, однозначная проверка ответов и удобство для начинающего важнее косметического разнообразия. Спорные формы проверять по авторитетным нормативным источникам.
5. Для упражнения и мини-проверки — ровно 3 жизни. **После первой же неправильной отправки** сразу показывай правильный ответ, все допустимые альтернативы и объяснение, по возможности причину ошибки; каждая красная отправка расходует 1 жизнь и не даёт зачёта. После третьей ошибки оставайся на вопросе с подробным разбором и добровольными кнопками «Повторить правило» и «Попробовать заново»; из теории можно вернуться к разбору. В нескольких пропусках подсвечивай ошибочные поля. Жёлтые ответы засчитываются без ошибки; политика ударений неизменна, текстовые поля имеют `á é í ó ú ü ñ`. Правильные варианты не должны систематически стоять в конце.
6. Перед завершением **нового или изменённого юнита** запускай `python -m espanol grammar-lint NN`, сверяй JSON с `content/grammar/schema.json` и `docs/grammar_fields.md`; все ERROR исправлять, каждое WARNING проверять, не считать эвристику доказательством. При работе с данными см. `docs/grammar_lint_guide.md`.
7. В конце работы укажи изменённые файлы/подразделы, проверенные сценарии, оставшиеся риски и остановись.

Если в этой папке уже существует `AGENTS.md`, **не заменяй его молча**: вручную объедини совместимые инструкции и разреши конфликты с владельцем проекта.
