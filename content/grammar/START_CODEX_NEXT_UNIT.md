# Задание для Codex: следующий юнит грамматики

Прочитай файл `CODEX_GUIDE_SPANISH_GRAMMAR.md` целиком и соблюдай его как стандарт качества.

**Целевой юнит: [УКАЖИ НОМЕР].** Проект — **отдельный раздел грамматики испанского языка (17 юнитов)**, не основной курс A0/A1.

1. Исследуй структуру именно этого юнита, существующие компоненты теории и практики, учебные предпосылки, логику ответов, прогресс и навигацию.
2. Составь план по подразделам: что сохранить, что исправить в теории, какие упражнения однообразны/угадываемы, какие 2–4 подходящих формата добавить, как проверить грамматику, ответы и мобильный UX. Количество форматов не квота — выбирай по целям темы.
3. Реализуй **один целевой юнит**, включая точные формулировки, разнообразие упражнений, адекватные дистракторы, ручной ввод там, где лучше, 3 ошибки, переход к связанной теории, жёлтый статус, испанские символы, корректное перемешивание.
4. При необходимости совместимо улучши общие компоненты и проверь другие юниты на регрессии. **Не переписывай их содержание**.
5. Прогони автоматические тесты, выполни ручной мобильный контроль и отчитайся о конкретных изменениях, тестах и известных рисках.
6. **Остановись.** Не приступай к следующему юниту без моей отдельной команды.

Если понадобится существенное изменение программы или архитектуры — сначала представь план на согласование. Не вводи сомнительные грамматические формы без проверки по авторитетным источникам.
