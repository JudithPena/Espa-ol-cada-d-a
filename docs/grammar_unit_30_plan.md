Цели: различить человека/действие/вещь; выбрать quién/quiénes по числу; использовать qué перед названием типа; сохранять a/de/con/para; поставить вопросительное сочетание и глагол по обычной нейтральной схеме; не спутать вопросительную тильду с относительным que.
