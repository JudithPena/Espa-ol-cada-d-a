# Юнит 65 · Estaba trabajando / trabajé — estaba + gerundio и pretérito indefinido

Источник: разворот юнита 65 (теория и упражнения 65.1–65.3). Уровень: A2. Предпосылки: юниты 56–57 (estar + gerundio в настоящем, глаголы состояния), 58–59 (indefinido), 63–64 (imperfecto и контраст с indefinido).

## 1. Цели
1. Образует estar в imperfecto + gerundio для всех лиц, ставит местоимение перед estar или в конце герундия.
2. Описывает действие, которое шло в определённый момент прошлого.
3. Различает процесс, прерванный событием (estaba + gerundio + indefinido), и два события подряд (indefinido + indefinido).
4. Не ставит в estaba + gerundio глаголы состояния и ir / venir, выбирая простой imperfecto.
