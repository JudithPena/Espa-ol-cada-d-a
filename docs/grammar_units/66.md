# Юнит 66 · Había trabajado — pretérito pluscuamperfecto

Источник: страницы 140–141 учебника, теория и задания 66.1–66.3 из предоставленных изображений. Уровень A2. Предпосылки: 58–59 (indefinido), 60–61 (haber + participio), 63–65 (imperfecto и контраст прошедших времён).

## 1. Учебные цели
1. Образует había/habías/había/habíamos/habíais/habían + причастие, в том числе неправильное.
2. Располагает два завершённых действия во времени: pluscuamperfecto раньше, indefinido позже.
3. Объясняет прошлую причину прошедшего результата, не подменяя состоянием в imperfecto.
4. Употребляет ya и todavía no применительно к прошлому моменту.
5. Сохраняет порядок возвратного местоимения и принимает оба положения todavía в отрицании.

## 6. Нормативные решения
| Форма/случай | Решение |
|---|---|
| `había habido un accidente` | грамматически корректное pluscuamperfecto безличного haber; перенесено из пункта 66.1.5 |
| `se había ido`, `se había teñido` | возвратное местоимение до haber |
| `ya había…` и `todavía no había…` | проверяется завершённость к контрольному прошлому моменту |
| `todavía no había recogido` / `no había recogido todavía` | оба нормативных порядка приняты зелёными |
| `había hecho` | неправильное причастие hacer уже известно из perfecto, повторено в упражнении |
| `estaba enfermo` | для состояния в прошлом нормален imperfecto, не обязателен pluscuamperfecto |
| `el avión se había ido` | адаптация исходного `se fue` сохраняет порядок событий, возможно более обычное `había despegado` при уточнении о взлёте |

Отдельные ссылки RAE/ASALE в этой среде не открывались; спорные формулировки не подаются как абсолютные запреты.
