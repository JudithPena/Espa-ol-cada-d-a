# Юнит 03 · Libro, libros — единственное и множественное число

## Задача
Переписать все теоретические экраны для начинающего ученика в живой, понятной манере без вмешательства в практику и оценивание.

## Аудит и выполненная переработка
| Блок | Что улучшено |
|---|---|
| 0. Singular / plural | Ситуация с книгами, согласование el/los и la/las, сохранение рода |
| 1. Гласные | Покупка фруктов, разница между безударными гласными и ударными á/é/ó |
| 2. Ударные í/ú | Допустимые варианты rubíes/rubís и bambúes/bambús, привычные menús/champús, региональные варианты |
| 3. Согласные | Список отелей, -es после l/r/n/d/j, rey/ley, исключения для заимствований |
| 4. Конечная z | Аквариум, замена z на c перед -es, сохранение акцента в lápices |
| 5. Конечная s | Дни недели и зонты, условия неизменяемости, разница mes/meses и autobús/autobuses |
| 6. Письменное ударение | Причина исчезновения акцента в leones и появления в jóvenes |
| 7. Парные предметы | Оптика и одежда, unas gafas и точное количество через par de |
| 8. Смешанная группа | Amigo/amiga → amigos, alumnos/alumnas, родители и ограничение для разных названий |

Итоговая памятка: 8 компактных опорных сравнений, обновлённые подписи и контрасты (в том числе león/leones и joven/jóvenes). Все правила и исключения сохранены.

## Стабильность
- В учебном JSON изменены только тексты теории, подписи сравнительных схем и `summary` юнита № 3.
- `id`, `number`, `learningOrder`, порядок разделов и количество итоговых узлов сохранены.
- Упражнения 3.1 (18 вопросов), 3.2 (10) и 3.3 (10), мини-проверки и ключи полностью неизменны.
- Структурные сравнения исходного и обновлённого JSON подтверждают неизменность упражнений, мини-проверок, порядка прохождения и испанских форм в схемах.
- Исправлен ранее падавший тест `tests/test_site.py`: вместо устаревшего числа 45 WebP он проверяет точное соответствие набору иллюстраций грамматики и уже существующей отдельной схемы расстояний юнита 12. Код сайта и юнит 12 не изменялись.
- Технический CI и сборка с предпросмотром: результаты отслеживаются в PR [#79](https://github.com/JudithPena/Espa-ol-cada-d-a/pull/79).

Теоретические экраны и `summary` на 320 / 390 / 768 / 1280 CSS px. Прямые скриншоты этих четырёх размеров при редактуре не снимались: использован GitHub CI и предпросмотр, но браузерный сценарий, который проходит все 9 экранов именно юнита 3, в данном изменении не добавлялся.
