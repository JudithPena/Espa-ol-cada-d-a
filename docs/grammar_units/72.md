# Юнит 72 · Habría, podría… — condicional simple: неправильные глаголы

Источник: разворот юнита 72 (страницы 152–153: теория и упражнения 72.1–72.4), присланный автором 14 ноября 2026. Уровень A2.

Предпосылки: юнит 71 (окончания и три значения condicional), прошедшее время indefinido (юниты 58–59), me gusta / me importa (юнит 55). Юнитов 62–70 на сайте нет:
- основы habr-, tendr-, har- и другие вводятся как новый материал, без опоры на futuro;
- в сравнениях «догадка / факт» стоят формы imperfecto (tenía, había, sabía), который ещё не пройден. В теории сказано, что это ещё одно прошедшее время, и в этих парах оно сообщает факт. Выбор в 72.3 решается по смыслу «знаю / предполагаю / прошу», а не по форме: у каждой фразы есть context с переводом;
- imperfecto de subjuntivo в окружении (72.1.3 cerráramos, 72.1.4 fueras) переведён.

## 1. Цели

1. Образует condicional одиннадцати неправильных глаголов по трём группам основ.
2. Употребляет неправильные формы для возможности, которой нет, и для совета.
3. Выражает догадку о прошлом через condicional и отличает её от точного факта в прошедшем.
4. Строит вежливую просьбу с ¿podrías / podría…? и ¿te / le / os / les importaría…? по адресату.

Добавлено от себя: остальные глаголы (ir, ser, dormir) образуют condicional правильно; habría в значении hay — одна форма (заметка и вопрос 72.1 №4); с poder местоимение может стоять перед глаголом (¿Me podrías ayudar?); вежливое ¿Podías…? в разговоре — не ошибка.
