# Памятки 60–61: опубликованные карты

Источник: https://espanolcadadia.pages.dev/
Код сайта: 905a236d6ceff8b9e72790c5ed82a44c980ac741.

Проверены реальные опубликованные памятки на 320, 390, 768 и 1440 px. Восемь проверок макета прошли: изображения загружены, горизонтального переполнения нет, нижний вывод доступен над кнопками, завершение работает, переход 60 → 61 загружает следующий юнит и сохраняет результаты. Также проверены прежние памятки 1/59, тёмная тема и масштаб 125%.

Полные снимки показывают всю прокрутку. При экспорте расширена только вертикальная область; ширина, размеры текста, карточек и сетка соответствуют реальному экрану.
