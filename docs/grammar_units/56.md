# Юнит 56 · Estoy viendo las noticias — estar + gerundio

Источник: теория, стр. 120, и упражнения 56.1–56.3, стр. 121; присланы автором 12 ноября 2026 года. Раздел: самостоятельная грамматика, A1. До юнита 56 в репозитории есть 53 юнита (53–54 ещё не загружены). Зависимости: формы estar уже известны из юнита 43, возвратные местоимения — из юнитов 39–40; образование герундия для данного урока объясняется здесь, не требует юнита 98 книги.

## 1. Цели

1. Составлять estar в presente + gerundio для действий прямо сейчас; правильно согласовывать estar с лицом.
2. Образовывать регулярные -ando/-iendo и нужные для заданий формы haciendo, viendo, leyendo, durmiendo.
3. Описывать временное положение дел с hoy, esta semana, este mes, últimamente.
4. Передавать частое повторение с siempre, todo el rato, todo el día и уместным эмоциональным оттенком.
5. Употреблять возвратные местоимения перед estar и после gerundio, включая акцент: duchándome, vistiéndose, acostándonos.

## 6. Нормативные решения

- Для текущего действия и временных ситуаций используется estar + gerundio; обычное настоящее время тоже может описывать некоторые ситуации, поэтому в заданиях указаны рамка и конкретная модель.
- Для повторения siempre + gerundio не обязательно выражает раздражение, возможен иной эмоциональный оттенок. В вопросах с жалобой оттенок задан контекстом.
- У возвратных глаголов обе позиции местоимения нормативны: me estoy duchando / estoy duchándome, se está vistiendo / está vistiéndose, nos estamos acostando / estamos acostándonos. Все реальные варианты перечислены в answers.
- При присоединении местоимения графическое ударение сохраняет ударный слог: duchándome, vistiéndose, acostándonos. Упражнения используют строгий режим accentPolicy.
- Из книги в явном виде взяты деления regular: -ando / -iendo и частотные особенности leyendo, haciendo, viendo, durmiendo, достаточные для всех приведённых заданий.
