# План юнита 20 — Todos, algunos, unos, ninguno…

Юнита 20 в проекте ещё нет; предыдущий — полные притяжательные формы. Источник: пользовательские страницы 48–49. Основной курс и JSON юнитов 1–19 не меняем. Используем существующие ввод, выбор, сборку, два пропуска, карточки данных facts, три статуса, сохранение и повторение теории.

Цели: различить всю группу/часть/один/ноль; согласовать формы; сократить alguno/ninguno перед мужским существительным; употребить de при выборе из группы; поставить no в зависимости от позиции отрицательного слова; заменить названное существительное.

| Теория | Практика | Адаптация и контроль |
|---|---|---|
| 1. Все, часть, один, ноль | 20.1: 8 коротких сочетаний по наглядным количественным карточкам | Сохранить предметы и свойства рисунков; дать точные данные вместо неясных штрихов скана. Для части группы принять algunos/unos и согласованные формы |
| 2. Todo el / todos mis / todos nosotros | начало 20.2 | Одна компактная схема; показать согласование и место уже изученных артиклей/притяжательных |
| 3. Algún / ningún перед существительным | 20.2: 7 исходных контекстов | Явно указать «вся семья», «все мои подруги»; вопросы принимают нормативные un/algún. Не делать глобальное биологическое утверждение о слонах: речь о рационе в конкретном парке |
| 4. Uno/alguno/ninguno de… | 20.3: 6 исходных контекстов | В части вопросов есть несколько допустимых сочетаний; явно выбрать ноль/одного по смыслу, de не дублировать |
| 5. Ninguno antes / no… ninguno después; формы без существительного | 20.4: 5 диалогов + 4 исправления | Два самостоятельных пропуска в первом диалоге; две сборки для порядка отрицания; no добавляется только там, где нужно |

Всего 30 практических вопросов и 10 мини-проверок с выбором. Форматы: наглядные данные→ввод сочетания, ввод формы/сочетания по ситуации, мини-диалог с двумя пропусками, сборка и исправление ошибки. Ни одно упражнение не превышает 15 вопросов: существующий лимит равен трём ошибкам; мини-проверки без жизней.

Проверки: полное прохождение, все альтернативы, ningún/ningun (жёлтый), ninguno вместо ningún (ошибка), ñ/n, единственное число глагола с ninguno de, три ошибки и нужная теория, сохранение двух пропусков, повтор ошибок, перемешивание, переход 19→20, завершение без 21; телефоны 320/390 и планшеты 800/1024, сокращённая видимая область, семь испанских клавиш. Исходные sourceRef сохраняем, добавления помечаем extra. Старые файлы защищаем хешами; изменяем только размеры курса в общих тестах и добавляем тесты нового юнита.
