# Методика раздела «Грамматика»: что улучшить

Основание — [отчёт аудита](AUDIT_REPORT.md). Здесь не перечень ошибок, а предложения: как учить лучше,
не усложняя интерфейс. Полностью вычитаны 13 юнитов (1, 3, 5, 7, 13, 16, 21, 26, 29, 32, 38, 39, 44);
по остальным выводы опираются на сканеры.

Ритм «теория → практика → теория → практика» сохраняется: он работает, и все 45 юнитов уже
построены по нему.

## Что уже хорошо и что стоит сделать образцом

- **Точные правила без ложных абсолютов.** Юнит 44 прямо говорит «не своди выбор к „навсегда или ненадолго“»;
  юнит 5 объясняет, что описание не всегда требует артикля (`Es profesora de español`).
- **Допустимые варианты с жёлтым пояснением** вместо «неверно»: `la pilota`, `la jefe`, `cualquiera tienda`.
- **Ситуация перед формой.** В юнитах 21, 32, 38, 44 ученик сначала читает, что происходит, и только
  потом выбирает форму.
- **Юниты 15–17** — лучшие по набору действий: прочитать данные, собрать фразу, сказать иначе,
  продолжить реплику.

Образцы для новых юнитов: **16** (сравнение по данным и переформулировка), **21** (ситуации и исправление
ошибок), **38** (роли в предложении), **44** (смысл раньше формы).

## 1. Мини-проверки: из формальности в настоящую проверку

**Сейчас.** 424 вопроса, все — выбор; в 147 из 188 проверок два вопроса с тремя вариантами.
Два вопроса с тремя вариантами угадываются вслепую в одном случае из девяти и ничего не говорят
о понимании. В юнитах 1–3 неверные варианты — несуществующие слова.

**Предложение.**

- Дать мини-проверке одну задачу: убедиться, что ученик **понял только что прочитанное правило**,
  до того как перейдёт к упражнению. Для этого достаточно двух–трёх вопросов, но разных:
  один на узнавание, один на воспроизведение (короткий ввод одной формы).
- Неверные варианты брать из типичных ошибок, а не из несуществующих слов.

| Сейчас (юнит 3, раздел 4) | Лучше |
|---|---|
| `hotel → ___`: `hotels` / `hoteles` | Ввод: `hotel → ___` (ученик пишет `hoteles`) |
| `reloj → ___`: `relojes` / `relojs` | Выбор с настоящей развилкой: `rey → ___`: `reyes` / `reys` / `reis` — этот вопрос уже есть и он хороший |

| Сейчас (юнит 1, раздел 2) | Лучше |
|---|---|
| `El cocinero → ___`: `la cocinera` / `la cocinero` / `el cocinero` | Ввод женской формы: `el cocinero → la ___`. Выбор оставить для настоящей развилки: «У какого слова меняется только артикль?» — `cocinero` / `taxista` / `profesor` |

- Вопросы «достаточно одного из двух верных» (9 штук) заменить вопросом с одним верным ответом
  или вводом, где принимаются оба.
- У каждой мини-проверки — своя инструкция (сейчас пустая у 65, общая у 98).

## 2. Убрать то, что решает задачу за ученика

Три механизма сейчас позволяют пройти упражнение, не применяя правило.

### 2.1. Подпись-подсказка (юниты 5, 7, 8)

Русская подпись должна описывать **ситуацию**, а не называть категорию правила.

| Сейчас (5.2) | Лучше |
|---|---|
| «Просто сообщи национальность человека.» — `Luis Miguel es ___ mexicano.` | Без подписи или с переводом фразы: «Луис Мигель — мексиканец.» Решение ученик принимает по испанскому предложению |
| «Нужен ли здесь артикль?» — `Es ___ abogado muy bueno.` (ответ всегда «нужен») | Та же общая подпись у всех вопросов упражнения, включая те, где артикль не нужен |
| «Представь человека… Выбери неопределённый артикль.» | «Тебя спрашивают, кто такой Луис Мигель. Ты отвечаешь: это один певец.» |

Правило для автора: если закрыть испанскую фразу и оставить подпись, ответ не должен угадываться.

### 2.2. Вариант, который никогда не верен (юнит 7 и другие)

Во всём юните 7 «Без артикля» предлагается 66 раз и не верен ни разу. Два пути:

- убрать вариант там, где он не имеет смысла, и честно оставить выбор из двух;
- лучше — добавить в упражнение несколько вопросов из предыдущих юнитов, где он верен
  (`Soy ___ médico`, `No tomo ___ azúcar`). Это заодно даёт повторение юнита 5.

### 2.3. Предсказуемый ответ в серии

В 3.3 все десять ответов строятся одинаково. Достаточно двух–трёх контрастных вопросов, которые теория
уже объяснила:

- `Mi hermana y mi prima son altas.` → `Mis ___ son altas.` — здесь мужской род не подходит;
- `un toro y una vaca` — пара, которую нельзя назвать `toros`;
- группа только из женщин: `tres alumnas`.

## 3. Длинные серии: делить по смыслу, а не сохранять все пункты учебника

**Сейчас.** 7.1 — 39 вопросов «`un` или `el`», 2.1 — 32, 8.3 — 27, 14.1 — 24. Это следствие негласного
правила «сохранить все исходные позиции учебника».

**Предложение.**

- Потолок — 12–15 вопросов на упражнение. Длинное упражнение делить на части с разными действиями.
- На примере 7.1: три истории («Фильм», «Картина», «Питомцы») уже есть. Сделать три упражнения
  по 8–12 вопросов с нарастающей самостоятельностью:
  1. «Фильм» — выбор из двух (первое упоминание или повторное);
  2. «Картина» — ввод артикля;
  3. «Питомцы» — собрать два предложения или дописать продолжение истории.
- Не разбивать одно предложение на четыре вопроса (7.1#12–15): один вопрос — одно решение.
  Остальные слова предложения оставить написанными.
- Пункты учебника, которые ничего нового не проверяют, можно не переносить. Покрытие темы важнее
  покрытия страницы.

## 4. Больше одного действия на тему

**Сейчас.** В юнитах 18–45 71 % вопросов — «впиши форму в пропуск». Юнит 13: 43 вопроса с одной операцией.

Не нужно вводить квоты. Достаточно, чтобы в каждом юните ученик сделал **три разных действия**
из списка ниже. Все они уже возможны в движке, кроме двух последних.

| Действие | Как выглядит | Пример из курса |
|---|---|---|
| Выбрать по ситуации | короткий выбор с настоящей развилкой | 44.1 |
| Образовать форму | ввод слова | 3.1 |
| Найти и исправить | ввод исправленной части | 21.4#6–7, 32.2b#3 |
| Сказать иначе | исходная фраза → новая | 16.3 |
| Ответить собеседнику | продолжение реплики | 16.4, 32.3 |
| Собрать фразу | плитки с 2–3 лишними словами | 16.1 |
| Объяснить различие | выбор объяснения | 44.2#11, 44.3#9 |
| Сопоставить (нет в движке) | пары «ситуация — фраза» | для `ser / estar`, `lo / la / le` |
| Распределить (нет в движке) | слова по группам | для рода, `el / la / ∅`, типов прилагательных |

**Для юнита 13 конкретно:**

- 13.1 оставить как ввод, убрав семь вопросов, где ответ равен подсказке, и оставив один–два таких
  как ловушку;
- 13.2 сделать распределением: «меняется по роду / не меняется» (`alegre`, `trabajador`, `marrón`, `feliz`);
- 13.3 посвятить своей теме: `buen / bueno / buena`, `mal / malo / mala` и место прилагательного —
  сборка `un buen profesor`, исправление `un bueno día`.

**Сборка фраз.** В 79 заданиях из 148 банк состоит только из слов ответа. Добавлять 2–3 слова,
которые отражают типичную ошибку (`un otro`, `cualquier de`, `Lo te`), и не выделять первое слово
заглавной буквой.

## 5. Пояснение должно отвечать на ошибку ученика

**Сейчас.** 120 вопросов получают одно и то же предложение («Проверяем сотни и порядок частей;
написанные слова не повторяем»). Пояснение одинаково для любого неверного ответа.

**Предложение (по возрастанию трудоёмкости).**

1. **Убрать шаблонные фразы.** Пояснение называет то, что решает именно этот вопрос.

   | Сейчас (26.2#3, `205 dólares`) | Лучше |
   |---|---|
   | «doscientos cinco dólares. Согласуем сотни и окончание uno с названием валюты.» | «`Dólares` — мужской род, поэтому `doscientos`. Между сотнями и единицами `y` не ставим.» |

2. **Пояснения к ожидаемым ошибкам.** В основном курсе уже есть поле `mistakes` — пояснения к типичным
   неверным ответам. Перенести эту идею в грамматику: `mistakes: {"doscientas cinco": "…", "doscientos y cinco": "…"}`.
   Достаточно одной–двух записей на вопрос там, где ошибка предсказуема.
3. **Показывать, где ошибка.** Для вопросов с несколькими пропусками — подсветка неверного поля (E-03).
   Для длинного ввода — подсветка первого места расхождения с ближайшим верным ответом.

Отдельно: неверный пример в теории не должен выглядеть как образец. Форму-ошибку (`ciento y veinte`)
оформлять зачёркнутой или с пометкой «так не говорят».

## 6. Исправление ошибок, которое проверяет понимание

**Сейчас.** После ошибки ученик видит верный ответ и через минуту вводит его же; неверные попытки
исправления бесконечны (E-04).

**Предложение — три шага, каждый полезен сам по себе.**

1. **Вторая попытка до показа ответа.** После первой ошибки не показывать ответ, а дать подсказку-правило
   и одну повторную попытку. Жизнь списывается один раз. Ответ показывается после второй неудачи.
   В основном курсе такая вторая попытка уже есть для ввода.
2. **Исправление на похожем вопросе.** У вопроса может быть необязательный `retry` — вопрос-близнец
   на то же правило (`hotel → hoteles` / `papel → papeles`). В работе над ошибками показывать его.
   Где близнеца нет — как сейчас.
3. **Ошибки возвращаются позже.** Вопросы, на которых ученик ошибся, предлагать в начале следующего
   юнита блоком «Вспомни» из 3–4 вопросов (см. п. 7).

## 7. Повторение между юнитами

**Сейчас.** Каждый юнит замкнут. Пройденное не возвращается; итоговой проверки юнита нет.

**Предложение.**

- **«Вспомни» в начале юнита:** 3–4 вопроса из предыдущих юнитов — сначала те, где были ошибки,
  затем случайные из связанных тем. Без жизней, с обычным разбором.
- **Смешанная практика в конце блока тем.** После артиклей (4–11), после местоимений (34–41),
  после `ser / estar / tener` (42–45) — короткое упражнение из вопросов разных юнитов блока.
  Именно смешение заставляет выбирать правило, а не применять то, что в заголовке.
- **Связи между юнитами.** Необязательное поле `requires` у юнита: какие темы предполагаются
  известными. Оно же подскажет, откуда брать вопросы для «Вспомни».

Для этого не нужен новый интерфейс: это обычные упражнения, собранные из существующих вопросов по `id`.

## 8. Порядок курса и уровни

**Наблюдение.** Юниты идут в порядке справочника: `ser`, `estar`, `tener` объясняются в 42–45,
но формы `soy`, `es`, `tiene`, `quiero`, `he visto`, `hablé` используются с первого юнита. Русский перевод
ситуации это смягчает, но начинающий, идущий по номерам, сорок юнитов работает с глаголами, которых
ему не объясняли. Уровни проставлены неровно (`cuyo` — A2).

**Предложение.**

- Оставить номера как есть (это каталог) и добавить поверх них **рекомендуемые маршруты**:
  «С нуля» (1–3 → 42–45 → 4–7 → 13 → 18 → 34…), «Артикли», «Местоимения». Маршрут — это список id
  в одном файле; движок уже умеет «следующий урок».
- Уровни пересмотреть по Plan Curricular del Instituto Cervantes одним проходом и показывать ученику
  как ориентир, а не как замок.
- В упражнениях ранних юнитов не использовать времена, которые не нужны для проверяемого правила
  (5.2: `se ha hecho`, `era`, `fue`), либо всегда давать перевод фразы.

## 9. Теория

Теория — сильная часть курса. Точечные предложения:

- **Одно правило — один экран — сразу вопрос.** В юните 3 перед первым упражнением семь разделов
  и 21 мини-вопрос. После п. 1 (мини-проверки с вводом) первое упражнение 3.1 можно сократить
  и превратить в смешанную проверку всех семи правил.
- **Длинные разделы делить.** Медиана — 79 слов на раздел; разделы по 175–249 слов (28.2, 41.3, 44.1)
  лучше разбить на два экрана с примером между ними.
- **Наглядность — там, где она объясняет.** Схемы «кто → кому → что» в юните 38 хороши. Сюжетные
  иллюстрации есть только в 4–14, 34, 35; добавлять их в каждый юнит не нужно. Нужнее схемы для тем
  с ролями и порядком слов (36–39: место местоимений; 28–29: что к чему относится).
- **Аудио.** Примеры в теории озвучены; в упражнениях после ответа стоит давать прослушать верную
  фразу целиком — это бесплатное подкрепление.

## Как измерить, что стало лучше

Без метрик улучшения останутся ощущением. Достаточно локальной статистики в браузере ученика
(без сервера), которую автор может посмотреть на своём прогрессе:

- доля вопросов, решённых с первого раза, по юнитам и упражнениям — слишком высокая (выше 95 %)
  означает «угадывается», слишком низкая (ниже 60 %) — «не объяснено»;
- на каких вопросах чаще всего теряются жизни;
- сколько упражнений провалено и сколько раз открыта теория после провала.

Сейчас хранится только число верных ответов лучшей попытки. Нужно дополнительно хранить счётчики
ошибок по вопросам — это несколько байт на вопрос.
