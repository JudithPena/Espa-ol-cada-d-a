# ТЗ №12: тема следующего урока на экране завершения

Общий экран успешного завершения юнита показывает компактный блок непосредственно перед кнопкой «Начать следующий урок»: номер, полное испанское название и русское описание темы. Все поля берутся из следующей записи COURSE.grammar — порядок и названия не задаются отдельной таблицей. Для неизвестного текущего id следующий урок не угадывается.

Уже пройденный следующий урок получает подпись «Уже пройден · можно повторить» и остаётся доступным для запуска с начала. Если следующего юнита нет, выводится «Все уроки раздела пройдены!» и основная кнопка «К списку уроков». Возврат на главную и к разделам текущего урока сохранён; список доступен со всех экранов завершения.

Доступность кнопки и запуска проверяет один gCanStartUnit: существующая проверка маршрута all либо возможность повторить полностью пройденный юнит, плюс наличие шагов. В нынешних 17 юнитах межурочных замков нет; они не добавлены. Если общая проверка доступа возвращает запрет для незавершённого урока, его тема остаётся видимой с подписью «Следующий урок пока недоступен», а активной кнопки запуска нет. Повторная проверка при клике защищает от устаревшей кнопки. Этот сценарий проверен с тестовым запретом доступа, без создания отдельной системы блокировок.

Кнопка списка использует прежний обработчик с завершением плеера и очисткой выбранного юнита: так открывается список всех уроков, а не снова экран завершения. Результаты, опыт, текущий сохранённый прогресс и содержимое курса не меняются. Карточка переносит длинные заголовки целиком, без многоточия и горизонтальной прокрутки.

## Проверки

- 215 Python-тестов и 95 JS-тестов прошли; валидатор курса и сборка сайта — без ошибок.
- Для всех 17 экранов проверены реальные номер, название и описание следующего урока, положение блока перед кнопкой и сохранность статистики.
- Реальным обработчиком клика проверены все 16 переходов и возврат из 17-го юнита к списку; отдельно проверены повторно проходимый и недоступный урок, неизвестный id, порядок курса с отличающимися номерами и экранирование заголовка.
- Браузерная проверка всех 17 экранов и переходов при ширине 320, 390, 800 и 1024 пикселя, включая искусственно длинный заголовок.
