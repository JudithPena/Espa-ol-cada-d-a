Итого 31 практическое задание + 8 мини-проверок. К исходным 30 позициям добавлено исправление porque → por qué: оно проверяет частую ошибку написания вопроса и делает блок причины/цели достаточно длинным для проверки лимита трёх ошибок. Форматы: короткий ввод по выделенному ответу, сборки, исправление, интервью с видимой ответной репликой. У смешанной практики перечислены все связанные theorySections по порядку. Не требуем выбирать между двумя нормативными вариантами направления как между верным и ошибочным.

Риски: в исходном 32.2.8 вопрос ошибочно сохраняет первое лицо no pude — исправить на no pudiste при вопросе собеседнику. В интервью желание работать в Испании может быть целью и мотивом: para qué / por qué оба могут соответствовать ответу. Для способа поездки не подменять вопрос вопросом о причине.

Проверены DPD: [dónde](https://www.rae.es/dpd/dónde), [adónde](https://www.rae.es/dpd/adónde), [cuándo](https://www.rae.es/dpd/cuándo), [cuánto](https://www.rae.es/dpd/cuánto), [cómo](https://www.rae.es/dpd/cómo), [porqué](https://www.rae.es/dpd/porqué). Нельзя запрещать dónde для направления; для статичного места не принимаем adónde. Значимые вопросительные тильды обязательны. Различие por qué / porque объясняем без нового раздела на все четыре porques.
