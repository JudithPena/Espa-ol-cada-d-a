# Бот на Cloudflare

Бот @Eduardo_maestro_bot работает на Cloudflare Workers (код — `bot/`) и делает три вещи:

1. **Публикует уроки вовремя.** Каждый час он смотрит время по Киеву, и в часы `PUBLISH_HOURS`
   (`bot/wrangler.toml`, сейчас 9 и 15) запускает на GitHub workflow «Публикация урока». У Cloudflare
   расписание точное, а `cron` в GitHub Actions опаздывает на 5–9 часов. Сама публикация, лимит постов в день
   и `state/state.json` — как раньше, в GitHub. Переход на зимнее время бот учитывает сам.
2. **Личные повторения в личке.** `/repaso` — до 10 слов: те, что пора повторить, и до 5 новых из уже
   вышедших уроков. Новое слово ученик сначала видит карточкой (короткий разбор: чтение, значение, примеры,
   сочетания, ловушка — `content/repaso/`, правила — `docs/repaso_guide.md`) и нажимает «Дальше»; потом
   выбирает перевод из 4 вариантов, и бот сам видит, верно ли. У каждого своё расписание (система Лейтнера):
   слово, которое помнят, возвращается через 1, 3, 7, 14, 30, 60, 120 дней; забытое — через 3 карточки этого
   же повторения (если они ещё есть) и снова на следующий день. `/progreso` — сколько слов выучено.
   Прогресс хранится в Cloudflare KV (`espanol-cada-dia-srs`).
3. **Выпускает разборы видео по расписанию.** Если у разбора в `content/videos/` есть `publish_at`
   (время по Киеву, ровный час), в этот час бот запускает workflow «Разбор видео» в канал (`VIDEO_WORKFLOW`)
   и пишет автору, что разбор ушёл. Расписание — `bot/data/videos.json` (его выгружает `bot-data`).
   Подробнее — `docs/video_guide.md`.

В конце каждого урока — ссылка «🔁 Повторить слова урока» (`t.me/Eduardo_maestro_bot?start=l-<id урока>`):
она открывает бота сразу на словах этого урока, а оставшиеся до 10 карточки бот добирает словами прошлых
уроков, которые пора повторить. В уроках без новых слов (тесты, повторения) ссылка ведёт
на обычное повторение (`?start=repaso`). Имя бота для ссылки — `bot` в `content/course.yaml`.

Бот показывает слова только тех уроков, которые уже вышли в канал: список он читает из `state/state.json`
на GitHub. Слова и озвучка выгружаются из курса (`python -m espanol bot-data`), когда workflow
«Бот на Cloudflare» (`.github/workflows/bot.yml`) выкладывает бота. Он запускается сам после правок
в `content/` или `bot/`.

## Как включить (один раз)

Все ключи — только в GitHub Secrets (репозиторий → Settings → Secrets and variables → Actions →
New repository secret). В чат и в файлы репозитория их не пишите.

1. **CLOUDFLARE_API_TOKEN.** dash.cloudflare.com → справа вверху профиль → My Profile → API Tokens →
   Create Token → шаблон **Edit Cloudflare Workers** → в Account Resources выберите свой аккаунт →
   Continue to summary → Create Token. Скопируйте токен в секрет `CLOUDFLARE_API_TOKEN`.
2. **CLOUDFLARE_ACCOUNT_ID.** dash.cloudflare.com → Workers & Pages: справа будет Account ID.
   Скопируйте его в секрет `CLOUDFLARE_ACCOUNT_ID`.
3. **BOT_GITHUB_TOKEN** — чтобы бот мог запускать публикацию. github.com → Settings → Developer settings →
   Personal access tokens → Fine-grained tokens → Generate new token. Resource owner — аккаунт владельца
   репозитория, Repository access — Only select repositories → `Espa-ol-cada-d-a`, Permissions →
   Repository permissions → **Actions: Read and write**. Срок — год (запишите дату: потом токен нужно
   продлить, иначе бот пришлёт в личку предупреждение и уроки снова будут выходить только по `cron` GitHub).
   Скопируйте его в секрет `BOT_GITHUB_TOKEN`. Если репозиторий не ваш и fine-grained токен его не видит,
   подойдёт classic token с галочкой `repo`.
4. Actions → **«Бот на Cloudflare»** → Run workflow. Первый запуск дольше (минут 5–10): озвучиваются все слова,
   потом озвучка берётся из кеша.
5. **TELEGRAM_REVIEW_CHAT_ID.** Напишите боту `/id` и впишите число из ответа в секрет
   `TELEGRAM_REVIEW_CHAT_ID`. Это нужно сразу: теперь сообщения бота получает Cloudflare, и прежний способ
   «отправить тому, кто последним написал боту» (`--chat auto`) в «Тест урока в личку» и «Разбор видео»
   больше не работает — они шлют в этот чат. Потом ещё раз запустите «Бот на Cloudflare»: тогда бот сможет
   писать вам, если публикация не запустилась.
6. Проверьте: напишите боту `/repaso`.

## «Мои слова» (только для автора)

Личная колода автора: `/palabras` в чате `TELEGRAM_REVIEW_CHAT_ID`. Каждый день в `WORDS_HOURS` (сейчас 8:00 по Киеву; можно добавить вторую смену)
бот присылает, сколько сейчас новых слов (в смене до `WORDS_PER_DAY` = 10; если смен несколько, пропущенная не копится) и повторений, с кнопкой «Начать».
Новые слова — карточкой-разбором целиком, повторение — выбор перевода из 4 вариантов (`CHOICES`), интервалы те же, что в `/repaso`.
Слова — `content/mis_palabras/`, правила и формат — `docs/mis_palabras_guide.md`, код — `bot/src/deck.js`.
Остальным ученикам колода не видна, в меню команд `/palabras` есть только у автора.

## Напоминания

По средам и субботам в 19:00 по Киеву (`REMIND_DAYS` и `REMIND_HOUR` в `bot/wrangler.toml`) бот сам пишет
в личку каждому, кто уже хоть раз писал ему или нажимал ссылку из урока: «Время повторить слова!» с кнопкой.
Если повторять нечего, не пишет. Под напоминанием есть кнопка «Не напоминать», включить обратно — в `/progreso`.
Как выглядит напоминание, автор может проверить командой `/recordatorio` (работает только в чате `TELEGRAM_REVIEW_CHAT_ID`).

## Время публикации

Время меняется в `bot/wrangler.toml` (`PUBLISH_HOURS`, часы по Киеву через запятую), после коммита
бот перевыкладывается сам. В `publish.yml` остался только запасной `cron` поздно вечером (15:00 UTC):
если бот не выпустил урок, его выпустит GitHub, а если оба урока дня уже вышли, запуск ничего не делает.
Ранних `cron` в `publish.yml` не ставьте: GitHub опаздывает на несколько часов и выпустит урок раньше бота.


## Колода Гали

Вторая личная колода в том же боте. Слова — `content/mis_palabras/galya/NN_имя.yaml` (формат и правила как в `docs/mis_palabras_guide.md`),
чат Гали — секрет `GALYA_CHAT_ID` (Галя пишет боту `/id`, номер идёт в Secrets). Одно занятие в день в 16:00 по Испании (`GALYA_HOURS`, `GALYA_TIMEZONE` в `bot/wrangler.toml`), 5 новых слов (`GALYA_PER_DAY`), свой прогресс,
слов автора она не видит. Без секрета колода не работает.
