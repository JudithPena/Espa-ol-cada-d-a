# Разделение статических данных — план и критерии

База: `ccr-f4c9bfd6-txio5n`, 1d096b0, 11 ноября 2026.
Первоначальные измерения сделаны на f8e816b; итог сверён после обновления базы. Реализация в
`codex/split-static-learning-data`; без слияния и публикации.
Изучен P1/L1 `docs/a2_c2_platform_roadmap.md` в Mythos (файл пока отсутствует
в основной ветке); код и посторонние изменения Mythos не переносились.

## Исходные измерения

Обычная сборка с видео, без генерации MP3: index.html 20 526 144 байта.
В JSON до выноса теоретических иллюстраций: книги 14 215 553, уроки 3 216 703,
грамматика 10 330 539, видео 67 846, аватары 83 730 байт. Теоретические
иллюстрации уже выносились старой сборкой, поэтому эти числа не складываются
в размер HTML. Картинки (base64, с повторами): книги 12 187 019, уроки
2 104 243, грамматика 8 771 061, аватары 83 418 байт.
Шаблон 293 209, плеер грамматики 76 608 байт; JS в итоговом HTML с данными
20 437 384 байта. Без аудио: 48 файлов (41 иллюстрация, HTML, иконки, manifest).

## Варианты и решение

1. Только книги отдельным файлом: быстрый выигрыш, но файл книги снова растёт;
   не решает рост уровней и грамматики.
2. JSON по главе, уровню, юниту + компактная карта + самостоятельные изображения:
   выбран. Сохраняет текущие плееры, ID, hash/history и localStorage.
3. Новый фреймворк/API/R2: не требуется для L1; лишние зависимости и миграция.

Порядок: (1) книги/главы/картинки, измерение и проверка эквивалентности;
(2) уровни A0–C2 и грамматика; (3) загрузчик, регрессии и бюджет публикации;
(4) отчёт. Исходный учебный контент не изменяется.

Ресурсы получают SHA256 в имени. HTML перепроверяется при новом посещении;
хешированные ресурсы кешируются. Одновременные и повторные запросы объединяются;
ошибка не кешируется как успех. Применение загруженных данных не пишет прогресс.
При смене экрана результат старого запроса не должен возвращать пользователя назад.
Для повторения конструкций нужны уже пройденные уровни: загружать их до создания
сессии, не строить задания из пустых заглушек. `--fragment` остаётся автономным.

## Риски и критерии приёмки

- Ядро ≤ 1 500 000 байт; любой файл ≤ 25 MiB; весь каталог ≤ 20 000 файлов.
  Блокирующая проверка после копирования аудио в CI, предупреждение при 80% бюджета.
- Каталог не содержит blocks/quiz/questions глав и уроков. Открытие главы не
  загружает соседние главы; открытие грамматики не загружает все юниты.
- JSON после гидратации равен прежнему site_data (кроме URL изображений).
- ID, версии, порядок, допустимые ответы и оценивание не меняются; все ключи
  хранения и URL остаются прежними. Никаких миграций/очистки данных.
- Прямые ссылки книг, смена уровня книги, сборники, рассказы, browser back/forward;
  A0/A1, возврат к источнику/теории, звук, повторение, сохранённые попытки.
- Сетевой отказ/404/невалидный JSON: понятное сообщение, повторная попытка,
  возможность уйти в другой раздел; устаревший запрос не перехватывает экран.
- Холодный и повторный запуск, мобильная ширина, неизменность localStorage.
- Cloudflare Free: 25 MiB/файл, 20 000 файлов. Источник проверен 11.11.2026:
  https://developers.cloudflare.com/pages/platform/limits/ . Ограничение числа
  MP3 остаётся отдельным L7; новые файлы не бесконечны, бюджет контролируется CI.
- Полностью офлайн доступны лишь ранее кешированные данные; впервые открываемый
  материал требует сети. Смена публикации обновляет URL через новый HTML.

Восстановление структуры после гидратации проверяется на равенство всех полей,
включая слова, задания, альтернативы, источники, номера, версии и порядок.

JSON самого крупного уровня — 613 113 байт. Общие данные — 352 329 байт.

Озвучка не генерировалась заново и на основной сайт ничего не выкладывалось.
Текущий сборщик находит 3771 ключ озвучки (3730 уникальных MP3); с ними расчётное
число файлов — 4173, около 21% бесплатного бюджета Pages. Фактический каталог
с настоящим аудиокешем обязательно проверяется в site.yml перед wrangler.
Сохранён L7: перед массовым добавлением длинной озвучки B1–C2 потребуется
контролировать число файлов, затем объединять записи или переносить звук.
Это ограничение не связано с размером HTML и не снимается данным изменением.

## Эксплуатация и совместимость

- Источники content/, Telegram, bot/, state/ и код оценивания не меняются.
- Обычная сборка требует HTTP(S); для локальной работы: `python -m http.server
  --directory site 8000`. Загружать на Pages нужно весь каталог, включая `_headers`.
- `--fragment` сохраняет данные/изображения внутри HTML и не использует загрузчик.
- HTML отдаётся с no-cache; JSON/изображения имеют неизменяемые хешированные URL.
  Ученик получает новые материалы при следующей загрузке страницы. У открытого
  старого HTML после нового deployment могут отсутствовать старые ресурсы:
  на экране ошибки есть также «Обновить страницу», прогресс при этом сохраняется.
- В памяти повторно используется одна загрузка URL; Cache API сохраняет до 64
  недавно загруженных JSON между посещениями. При недоступном Cache API загрузка
  работает через сеть; изображения кеширует браузер. Офлайн не обещается для
  материалов, которые ещё не загружались или уже вытеснены из кеша.
- Каталог книг вынесен в самостоятельный JSON и загружается при входе в раздел;
  содержимое главы/рассказа скачивается только при его открытии. При прямой ссылке
  сначала загружается каталог, затем выбранный текст; hash не теряется. Соседние главы не предзагружаются.
- Уровни определяются метаданными, поддержаны A0–C2. Новые уровни не требуют
  изменения загрузчика; тест с C2 проверяет тот же контракт и сохранность ID.
- Для повторения навыков до начала сессии загружаются нужные пройденные уровни;
  текущие source/rule остаются индексами блоков того же урока.

## Проверки

- `python -m espanol validate` — без ошибок.
- `tests/test_site_assets.py`: бюджеты, SHA256, полная эквивалентность данных,
  этап книг, C2 и карта аудио.
- `tests/site_static_data.test.cjs`: настоящие JSON, все юниты, слова, старый
  прогресс/попытки, network error/404/HTML вместо JSON, retry, дедупликация,
  старый запрос после навигации, прямые ссылки, рассказы, сборники и кеш офлайн.
- Старые Python/Node проверки курса и грамматики сохраняются.
- `tests/site_static_browser.py`: Chromium через HTTP на 320/390/768/1280 px,
  прямые ссылки, back/forward, A0/A1, source, сохранённая сессия грамматики,
  failure/retry, повторное открытие из Cache API и сохранность прогресса.
  Выполняется отдельной задачей CI без секретов и без deploy.
- В этой среде обычный Chromium блокируется запретом Unix sockets; попытка
  установить headless shell получила невалидный архив CDN. Поэтому локальные
  браузерные замеры времени не выдаются за выполненные; CI сохраняет фактическую
  браузерную диагностику и размеры сетевых ответов как artifact.
