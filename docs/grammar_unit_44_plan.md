# Юнит 44 · Ser / estar — план

Начат после отчёта 43: 313 Python, 165 JS, все 38 UI-вопросов. Источник: страницы 96–97; 36 исходных позиций (9/9/10/8). Новый урок, предыдущие 43 сохраняем.

Проблемы источника: «permanente / temporal» не универсальный алгоритм; muerto — состояние независимо от длительности; города стоят на месте, но estar. Son/están casados оба употребляются, нельзя противопоставить их как верно/неверно. Este libro es/está interesante также допускает разные оценки; принимаем обе формы и объясняем оттенок. В прочих двусмысленных фразах добавляем конкретную речь о характере/состоянии/изменении. Не представляем все виды змей опасными. Examen бывает мероприятием и бумажным документом.

Цели: отличить характеристику от состояния/изменения; выбрать ser для события и estar для места людей/вещей; понимать listo, malo, aburrido, bueno, moreno, rico с обоими глаголами; согласовать форму; самостоятельно ответить по ясной ситуации. Все предпосылки в 42–43.
