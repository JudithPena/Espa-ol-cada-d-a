# Стиль объяснений в уроках

Курс — для русскоязычных, с нуля (A0→A1). Контент: `content/units/NN_*.yaml` (формат описан в README.md,
раздел «Как редактировать курс»). Автор канала попросил (дословно): «чтобы в постах не было опускания слов,
чтобы всё проговаривалось… не опускать слова если, чтобы, для того чтобы, тогда и другие, и если идёт правило,
то к каждому пункту пример, а не только один». По этим правилам переписан весь курс; новые и исправленные
уроки пишутся так же.

## Как писать

1. **Русские объяснения — полными связными предложениями**, как их произносит живой преподаватель.
   Не опускать глаголы и союзы: «если… то», «тогда», «чтобы», «для того чтобы», «потому что», «поэтому»,
   «когда», «значит», «означает», «читается», «падает», «ставится» и т. д.
   - Стрелка `→` и тире вместо сказуемого в объяснениях запрещены: «кончается на гласную → ударение на
     предпоследний слог» — плохо; «если слово заканчивается на гласную, то ударение падает на предпоследний
     слог» — хорошо.
   - Стрелка допустима только внутри цепочки форм, где показано превращение одной формы в другую
     (`profesor → profesora`, `hablar → hablo`), и то лучше обернуть её фразой («из profesor получается profesora»).
   - Конспектные «X — Y» в объяснениях превращайте в предложения: «**nosotros** — мы (мужчины…)» →
     «**nosotros** значит «мы», когда в группе есть хотя бы один мужчина…».
2. **Каждый пункт каждого правила — со своими примерами, по 2–3 и больше**, если хватает знакомых слов.
   Не один пример на всё правило, а примеры к каждому пункту. Касается блоков `rule`, `tip`, `note`, `latam`,
   пунктов `list` и ячеек `table`, где есть объяснение.
3. Тот же стиль — в пояснениях к викторинам (`explain`), в заданиях (`task`) и в обычном тексте уроков.
4. Тон дружелюбный, на «вы». Не раздувайте: пост читается за 5–10 минут; дописывайте слова там,
   где их не хватает, а не добавляйте новые абзацы ради объёма.

## Что не трогать при правке стиля

- `id` уроков, `kind`, порядок уроков, словарные строки `vocab` (формат словаря «слово — перевод» — это норма),
  правильность ответов в викторинах.
- Испанские диалоги и тексты для чтения, таблицы форм (`yo hablo`…), пункты упражнений `a => b`,
  заголовки (`header`), подписи — они и должны быть короткими.

## Главное ограничение: только пройденные слова

Каждое испанское слово (латиница) в уроке должно быть уже введено в этом или более раннем уроке — это проверяет
валидатор. Поэтому примеры берите:
- из слов, уже пройденных к этому уроку (проверка: `python -m espanol lookup слово` — покажет, в каком уроке
  слово появляется впервые; формы спряжения/множественного числа «открываются» только после своей грамматики);
- из новых слов этого же урока (`vocab`);
- из имён и географических названий в `content/course.yaml` (`names`, `roles`, `places`) — они разрешены везде:
  Carmen, Carlos, Isabel, Andrés, Madrid, Málaga, Sevilla и т. д.
- `code` в обратных кавычках валидатор не проверяет — используйте его только для букв, окончаний и
  намеренно неправильных форм, **не** как лазейку для непройденных слов.
- Новое слово в `vocab` добавляйте только в крайнем случае: если `lookup` пишет «в курсе не вводится» и в уроке
  меньше 8 новых слов. Формат строки — как у соседних.

Испанский в примерах должен быть безупречно правильным (ударения, род, формы). Если сомневаетесь в слове — берите другое.

## Ограничения Telegram (их тоже проверяет валидатор)

Пояснение к викторине (`explain`) — не длиннее 200 символов, вопрос — 300, вариант ответа — 100.

## Образец

Было:
```
1. Слово кончается на гласную, `-n` или `-s` → ударение на **предпоследний** слог: **ca**sa, **ta**xi.
2. Кончается на другую согласную → на **последний** слог: ho**tel**.
3. Есть значок ´ → ударение там, где он: ca**fé**, **mú**sica.
```
Стало:
```
1. Если слово заканчивается на гласную или на согласные `n` и `s`, то ударение падает на **предпоследний** слог: **ca**sa, **ta**xi, **ho**la, **Car**men, **Car**los.
2. Если слово заканчивается на любую другую согласную, то ударение падает на **последний** слог: ho**tel**, Ma**drid**, Isa**bel**.
3. Если над гласной стоит значок ´, то ударение падает именно туда, даже когда первые два правила говорят иначе: ca**fé**, **mú**sica, An**drés**.
```
Было: «Отбрасываем **-ar** и добавляем окончание лица: **-o, -as, -a…**»
Стало: «Чтобы получить нужную форму, отбросьте у глагола окончание **-ar** и добавьте окончание лица: **-o, -as, -a, -amos, -áis, -an**. Например, из hablar получается habl**o** — «я говорю», habl**as** — «ты говоришь», habl**a** — «он говорит».»

## Проверка (обязательно)

```
python -m espanol validate        # должно быть «✅ Ошибок нет»
python -m pytest -q               # все тесты зелёные
python -m espanol preview <номер или id урока>   # посмотреть, как выглядит пост
```
