# Разбор после последней жизни

Третья красная ошибка завершает попытку, но оставляет последнее задание и ответ ученика на экране. Под ним показаны введённый ответ, допустимые варианты и объяснение именно этого вопроса из q.explain. Перехода по таймеру нет. Кнопка «Вернуться к теории» открывает начало связанного блока из theorySections; после повторения доступна «Попробовать ещё раз» с новой попыткой и тремя жизнями.

Пока жизни остаются, неправильный ответ сопровождается retryHint либо подсказкой проверить форму и участников фразы. Готовый ответ, полное объяснение и подсветка правильного варианта скрыты. Жёлтые ответы засчитываются без потери жизни. Все допустимые answers участвуют в проверке; feedbackAnswers позволяет показать смысловые варианты без технических дублей.

Последняя ошибка сохраняется в attempt.lastError (индекс вопроса и ответ). Старая попытка без этого поля показывает последнее сохранённое неверное задание. Для ошибки в работе над ошибками восстанавливаются поля последнего исправления, а не исходной отправки. Лучшие результаты и ранее пройденные разделы не удаляются. Завершённые старые попытки сохраняют статус.

Для практики лимит равен трём, включая длинные упражнения, ранее получавшие дополнительные жизни. Мини-проверки 1–45 сохраняют режим без жизней; группы с limitedAttempt: true используют уже установленный лимит, включая исправления.

## Проверки

- Автоматический сценарий трёх разных ошибок по каждому практическому упражнению: последнее задание, ответ, объяснение, допустимые варианты, отсутствие «Далее» и «Проверить», блокировка повторной отправки, сохранение после повторного входа, точная теория и новая попытка.
- Регрессии выбора, текста, сборки, пропусков, жёлтого статуса, альтернатив, старых сохранений и лучших результатов.
- Браузер: 15.3, ошибки в сборке и выборе; первые две без раскрытия ответа; третья — разбор с двумя допустимыми вариантами. После обновления страницы и повторного открытия упражнения сохранены 0 жизней и последний ответ. По кнопке открыта теория «Чем я, чем ты: que yo, que tú», повтор начинается с тремя жизнями.
- Мобильный viewport 428 CSS px: горизонтального переполнения нет, разбор прокручивается, кнопка возврата доступна внизу. Проверен обычный компьютерный экран.

Основной курс A0–C2, его прогресс и грамматические JSON в этой задаче не менялись. Физическая клавиатура телефона и реальный скринридер отдельно не проверялись.

Итог на текущей версии: 47 юнитов, 179 практических групп. Validate — без ошибок; pytest — 350 passed; JS грамматики, основного курса и книг — 225 passed; сборка сайта и git diff --check успешны.

## Уточнение: итоговый разбор всех ошибок

После исчерпания жизней блок «Разбор ошибок» перечисляет все неверные отправки текущей попытки: номер вопроса, условие, ответ ученика, допустимые ответы и объяснение. Вводные фразы о спокойном чтении удалены. errorHistory хранит последовательность отправок, включая разные ошибки в одном вопросе при исправлении; последняя ошибка продолжает определять сохранённый экран задания. При повторе упражнения история очищается вместе со счётчиком. Для старых попыток восстанавливаются доступные исходные ответы и последнее исправление; ранее перезаписанные исправления восстановить невозможно.

Проверка уточнения: 179 практических групп сохраняют все три ошибки после повторного входа; отдельный сценарий — разные исправления одного вопроса и очистка истории при повторе. 177 JS-тестов грамматики, 49 JS-регрессий курса/книг и 350 Python-тестов прошли. В браузере подтверждены три карточки разбора, удаление вводной фразы и отсутствие горизонтального переполнения при 390 CSS px.
