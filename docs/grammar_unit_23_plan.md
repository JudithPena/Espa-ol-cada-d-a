Каждое поле ожидает только пропущенную часть; пример формата не раскрывает ответ. Вещь за деревом/в дереве не называем человеком. Нет искусственных форм nadie/nada по родам и числам. Вопросы с неизвестным человеком строятся нейтрально с alguien, без абсолютного запрета отрицательных местоимений в особых вопросах.
