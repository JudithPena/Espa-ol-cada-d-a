## Примеры решений

- 3.1 hotel: вместо hotel / hoteles — ввод hoteles. Ошибка hotels получает объяснение «После -l добавляем -es». В том же упражнении убраны все остальные слабые выборы.
- 1.3: madre / abuela / hermana вместо смешения родов. Для Pedro — hermano / nieto / hijo. Нужно прочитать семейные связи.
- 3.2: убраны дубли верного ответа цифрами и словами и случайные ошибки количества; оба способа записи по-прежнему принимаются при вводе.
- 5: вместо четырёх артиклей заведомо другого рода/числа — выбор между подходящим артиклем и ∅. Ситуации явно различают профессию, количество, вид продукта и привычку.
- 7: нулевой артикль с неопределёнными существительными во множественном числе не выдаётся за ошибку; в таких случаях сравниваются определённый и неопределённый артикли.
- 9.1: ученик выбирает Es la / Son las. Готовое Es/Son перед пропуском больше не подсказывает ответ. Для совместимости в прогрессе сохраняются прежние значения la/las.
- 13–14: слабые пары вроде fuerte / fuertes заменены вводом; в части вариантов национальности добавлена мужская форма единственного числа.
- 16: вместо положительного tan как якобы неправильного варианта сравнения использованы типичные ошибки согласования и iguales de.
- 17: варианты muy caro / más caro / el más caro различаются смыслом, а не случайным порядком слов.

## Что сохранено

Все unit.id, group.id, количество и порядок вопросов, sourceRef, learningOrder, ключи сохранения, правила замков и XP сохранены. Ни один прежний допустимый ответ не удалён: только добавлены la gorila и menúes. Изменены восемь отображаемых предложений 9.1 и инструкция к вводу menú. Снимок подписей обновлён только для этих обоснованных изменений.

Порядок вариантов задан в данных и не перемешивается при каждом показе: сохранённое значение ответа остаётся тем же при возврате или обновлении страницы. Завершённые результаты не сбрасываются; старый незавершённый выбор, заменённый вводом, становится редактируемым полем. В качественных заданиях содержание вариантов сохранено, в группах с систематической последней кнопкой меняется только размещение.
