# Три ошибки и возврат к правилу

Механика действует во всех 17 юнитах: 60 практических упражнений и мини-проверки используют общий счётчик на группу вопросов. Выбор ответа, обычный и многострочный ввод, два текстовых пропуска, сборка из слов и выбор слов в пропусках проходят через одну проверку.

## Поведение

1. В начале — три красных сердечка в верхней строке. Первая ошибка оставляет два сердечка, вторая — одно и предупреждение «Осталась последняя попытка».
2. Третья ошибка сразу прерывает упражнение, в том числе на последнем вопросе. Оно не получает зачёт или опыт. Показан экран «Пока не получилось. Давай повторим правило!» с кнопкой «Повторить теорию».
3. По кнопке открывается начало связанного блока теории. Если частей несколько, ученик последовательно просматривает их без мини-проверок. Иллюстрации можно увеличивать, как в обычном уроке.
4. На последнем экране появляется «Попробовать ещё раз». Упражнение начинается сначала, ответы очищаются, возвращаются три сердечка. В полном маршруте после успешного повтора продолжается следующий раздел урока.

После первой и второй ошибки сохраняются обычное объяснение и ручная кнопка «Далее». Пустой ответ не отправляется и не расходует попытку. Повторное нажатие после проверки не является новой отправкой. Возврат назад показывает уже проверенный ответ и не возвращает сердечко. «Повторить ошибки» после завершения продолжает ту же попытку с прежним счётчиком; новая попытка без потраченных сердечек возможна после успешного завершения либо после повторения теории при провале.

## Сохранение

Отдельный журнал `espanol-cada-dia.grammar-attempts.v1` сохраняет запись по `unit.id/group.id`: идентификатор попытки, `errors`, состояние, ответы и позицию повторения. Состояния: `active`, `failed`, `review`, `passed`. Текущий экран остаётся в прежнем `grammar-session.v1`.

При добровольном выходе попытка сохраняется. Кнопка «Продолжить урок» возвращает на сохранённый экран. Открытие другого раздела, юнита, «Начать сначала», обновление страницы и повторный вход в том же браузере не сбрасывают ошибки незавершённой попытки. Проверенные ответы нельзя перезаписать из старого экрана или второй вкладки. При восстановлении старой незавершённой сессии уже допущенные ошибки учитываются. Заработанные до обновления результаты сохраняются.

Журнал локален для браузера, как текущая попытка; успешный прогресс по-прежнему синхронизируется через `P.grammar`. Провал не удаляет прежние успешные оценки и опыт, в том числе при повторном прохождении ранее завершённого упражнения. Новый неудачный результат не открывает следующие разделы и не заменяет лучший результат. Явный сброс всего прогресса очищает и журнал попыток.

## Связь с теорией

У каждого упражнения явно заданы `theorySections` — индексы нужных частей, начиная с нуля. Загрузчик проверяет существование частей, отсутствие повторов и непустой список. Тесты дополнительно проверяют, что эти части стоят перед упражнением в учебном маршруте. У мини-проверки назначение — её собственный раздел.

В частности:

- 3.1 → части 0–6: правила множественного числа, начиная с первого экрана.
- 3.2 → часть 7: один предмет со словом во множественном числе.
- 3.3 → часть 8: смешанная группа.
- 17.1 → части 0, 1, 2; 17.2 → часть 5; 17.3 → части 3, 4; 17.4 → часть 6. Используются реальные связи, а не номера соседних элементов массива.
- 1.2 использует тот же начальный блок, что 1.1; 2.3 повторяет правила о роде предметов и животных целиком. Наличие двух упражнений подряд не отправляет ученика к случайной теме.
