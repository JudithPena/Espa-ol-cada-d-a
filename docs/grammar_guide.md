# Личная грамматика испанского

Автор присылает юниты по очереди. Из каждого готовим самостоятельный пост: понятное объяснение по-русски, примеры по-испански с переводом, типичные ошибки, упражнения и ответы с кратким разбором под <tg-spoiler>. Пишем своими словами; не копируем учебник целиком. Один юнит — один выпуск (при необходимости несколько сообщений).

Очередь: `content/grammar.json`, массив в порядке отправки. Новый юнит дописывать в конец. Сейчас очередь пуста: ждём первый материал автора. Формат:

```json
[{
  "id": "001_articulos",
  "title": "Артикли",
  "draft": false,
  "messages": [
    "<b>🇪🇸 Грамматика · Юнит 1 · Артикли</b>\\n\\nОбъяснение и примеры…",
    "<b>✍️ Практика</b>\\n\\nЗадания…",
    "<b>✅ Ответы и разбор</b>\\n\\n<tg-spoiler>Ответы…</tg-spoiler>"
  ]
}]
```

Текст — Telegram HTML, каждое сообщение до 4096 символов вместе с разметкой (консервативный лимит). Экранировать &, < и > в обычном тексте. Ответы отдельным сообщением: Telegram раскрывает все спойлеры одного сообщения вместе. `id` постоянный; отправленные посты не удалять и не переименовывать. `draft: true` у первого неотправленного поста приостанавливает очередь. Проверять качество и полноту объяснения и ключей перед добавлением.

Эдуардо отправляет следующий готовый юнит только в положительный личный `ADMIN_CHAT_ID` (секрет `TELEGRAM_REVIEW_CHAT_ID`), ежедневно в 09:00 Europe/Kyiv, с учётом перехода времени. Пустая очередь молчит. Новые посты начинают уходить в ближайшие 09:00 после успешной выкладки бота. Публикация курса и личные словари работают независимо.

Прогресс — KV `grammar:queue:<ADMIN_CHAT_ID>`: sent, lastDay, current. После каждого сообщения сохраняется позиция. Перед отправкой сохраняется pending: если ответ Telegram потерян или произошла ошибка, автоматическая отправка останавливается, чтобы не дублировать сообщение. Для восстановления проверить фактическую доставку в Telegram: если pending-сообщение пришло, поставить current.next = current.pending; если точно не пришло — оставить next. Затем удалить current.pending. Не сбрасывать sent/lastDay. Обработка требует доступа к Cloudflare KV; в логах будет Grammar delivery uncertain.

Правки content/grammar.json запускают существующий workflow «Бот на Cloudflare». Тесты: `cd bot && npm test`. Получатель не выбирается по последнему сообщению боту и не подменяется каналом.
