# Юниты 42–45 · Итог разработки

Работа выполнена последовательно 42 → 43 → 44 → 45. Перед каждым следующим юнитом сохранён отдельный план и отчёт с завершёнными проверками предыдущего. Это пакет из четырёх прямо запрошенных пользователем итераций, без перехода к 46. Основной курс A0–C2 и прежние 41 грамматический JSON не изменены.

В одном sourceRef может быть несколько сохраняемых полей ответа. Перечень и проверки — `tests/test_grammar_ser_estar_tener.py`.

## Методический аудит

Проверены все вопросы, допустимые ответы и объяснения. Сверены учебные действия, а не только названия форматов. Точных повторов prompt внутри групп не обнаружено. Сигналы преобладания короткого ввода и повторяющихся конструкций оценены вручную:

| Где | Сигнал и решение |
|---|---|
| 42.1: 1,5,6,7 | Повтор ¿De dónde…? сохранён для разных лиц и перехода вопрос → ответ. Не одна и та же форма в четырёх фразах. |
| 42.4 | Пять коротких диалогов различают время, день, цену и количество; es/son/somos зависят от смысла. Рядом исправление и самостоятельная реплика. |
| 43.2: первые семь ситуаций | Формы estar повторяются ради лица и согласования состояния; не семь одинаковых замен. Добавлены ответ собеседнику и исправление. |
| 43.3: первые шесть описаний | Одинаковый короткий формат сохранён для открытого/закрытого, чистого/грязного, выключенного и облачного; меняются число и состояние. Два следующих задания требуют объяснения и исправления. |
| 44.2: исходные 44.3.1–10 | Схожие пропуски специально сопоставляют событие, документ и здание. Три ¿Dónde…? и два examen проверяют разные референты. |
| 44.3 | Шесть смысловых пар требуют контекста. Нет универсального ключа «сегодня → estar» или «навсегда → ser». |
| 45.2: 1–5 | Сходные поля закрепляют чтение данных, yo/nosotros/ellos и отрицание; готовые формы в инструкции убраны. |
| 45.3 | Ситуации с разными ощущениями сохранены; добавлены сравнение sueño/cansado, исправление Estoy sed и ответ о страхе. |

Слабые бинарные пары не добавлялись. Дистракторы отражают лицо, число, неверную конструкцию или смысл; одна правильная трактовка задаётся контекстом. Там, где нормативно возможны разные ответы, проверка принимает их: например, son/están casados, es/está interesante. Преобладание ввода оправдано самостоятельным воспроизведением неправильного спряжения; количественной квоты на форматы нет.

Наглядность выбрана по содержанию: одна таблица форм на глагол, смысловые пары ser/estar, группы ощущений, конкретные данные о персонажах и диалоги. Она показывает грамматическое различие, а не предлагает угадать ответ по выражению лица. Не создано четыре одинаковые таблицы на одну тему.

## Точность и реализация

Правила сверены с RAE/ASALE: [DPD ser](https://www.rae.es/dpd/ser), [estar](https://www.rae.es/dpd/estar), [DLE tener](https://dle.rae.es/tener), [таблицы спряжения](https://www.rae.es/diccionario-estudiante/docs/conjugaciones-verbales.pdf), словарные статьи о listo, bueno, rico, moreno и aburrido. Спорные случаи и ссылки описаны в отдельных отчётах.

Сохранены soy yo; es la una/son las dos; местонахождение постоянных объектов с estar; muerto; различие события и предмета examen; шесть пар значений прилагательных; формы tener и все восемь ощущений. Норма не сведена к постоянному/временному. Указаны роли говорящего и формат ввода; все поля поддерживают á é í ó ú ü ñ, переход остаётся ручным.

Из общих производственных файлов изменён только список четырёх иконок в `espanol/grammar_player.js`. Оценивание, прогресс, лимит ошибок, загрузчик, шаблон сайта и основной курс не менялись. В тестах дополнен инвентарь и снимки; прежние проверки не удалены. Новые SHA256-снимки фиксируют сохранность юнитов перед каждым этапом.

## Проверки

Для каждого юнита браузером пройдены **все** мини-вопросы и упражнения: 38/38/48/35 экранов с вопросами; практика 30/30, 30/30, 40/40, 29/29. Проверены 320/360/390/428 CSS px. В 45 дополнительно вручную проверены жёлтый статус и три ошибки → точная теория → повтор; прежний лучший результат сохранён.

Автоматический интеграционный проход проверяет каждый принятый ответ, отрицательные ответы, черновики, обновление страницы, неудачную попытку, возврат к связанной теории, сброс при повторе и сохранность лучшего результата. Отдельные проверки охватывают осмысленные ударения esta/está, estas/estás, ñ, варианты ser/estar и смену лица tener. Общие регрессии сохраняют вставку букв, звук, перемешивание, сопоставление и работу старых упражнений.
