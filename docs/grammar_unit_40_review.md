Наглядность: схемы «сам себя / другого» и «Ана → Луис / Луис → Ана», двусторонний диалог, сравнение своих и чужих частей тела. Растровая иллюстрация не требуется: направление действия и местоимения прямо подписаны на схеме.

## Грамматика и неоднозначности

- Me/te/se/nos/os выбираются по действующему лицу; usted → se.
- Se при порезе, ожоге, переломе не объявляется намеренным действием на себя.
- В потенциально факультативных se-конструкциях с cortar pan, quemar cartas, tirar gafas проверяется значение уже написанной фразы, а не категорический запрет экспрессивного se.
- Для взаимных действий явно указаны участники и ситуация; nos lavamos не объявляется однозначным без контекста.
- Формы глаголов при преобразовании даны: проверяется местоимение и согласование, без требования вспомнить новое спряжение.
- Для отсутствующего местоимения принимаются ∅, дефис и тире. Для вопросительных фраз принимаются варианты с ¿ ? и без них; смысловые ударения сохраняются обязательными.

Сверено с [RAE/ASALE, se §1b–d](https://www.rae.es/dpd/se) и [pronombres personales tónicos §4–5](https://www.rae.es/dpd/pronombres%20personales%20t%C3%B3nicos). Данные предыдущих 39 юнитов сохранены по SHA-256. Общий движок: добавлен только значок нового юнита; оценивание и прогресс не менялись.
