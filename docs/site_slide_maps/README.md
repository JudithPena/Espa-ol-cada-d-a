# Карты экранов уроков сайта (A0–A1)

Карта — продуманная последовательность учебных шагов урока, составленная **до** правки его YAML
(ТЗ «Доводка A0–A1», раздел 1). По одному файлу на тему: `NN_тема.md`. Карта — источник порядка: сценарий
урока в `content/site/units/NN_тема.yaml` повторяет её.

## Что в карте урока

1. **Вводные:** примерная длина (шагов, минут), новая и повторяемая лексика, ключевые конструкции, порядок
   введения материала, типы интерактива, где самостоятельное воспроизведение, где итоговая ситуация, что
   проверяется, какие экраны удалены или объединены и почему.
2. **Таблица шагов:**

   | Шаг | Экран / тип блока | Что видит или делает ученик | Учебная цель | Что должен уже знать | Связь с предыдущим/следующим | Источник |
   |---|---|---|---|---|---|---|

   В колонке «Источник» — id диалога, текста или миссии, к которой привязан вопрос (`source`), или «—» для
   самостоятельного задания (`free`).
3. **Сигнатура** — одна строка `Сигнатура: …` с шагами, которые реально строит движок
   (`node tools/site_steps.cjs <урок>`). Тест `tests/site_course.test.cjs` сверяет её с движком: карта и урок
   не расходятся.

Обозначения сигнатуры: `T(блоки)` — экран объяснения, `W` — карточка слова, `C` — выбор, `I` — ввод,
`M` — пары, `S` — группы, `B` — сборка фразы, `F` — «Мастер фраз», `Q` — вопрос теста, `V` — вопрос на слово,
`~` — на слух, `@id` — источник, `R` — задание запланированного повторения (блок `review`), `×N` — N шагов подряд.
Шаги `R` появляются, только если навыку пора повториться; сигнатура в карте снята для ученика, который прошёл
все предыдущие уроки и ещё ни разу не повторял навыки (тогда повторить пора всё, что уже введено).

Карты не копируются по шаблону: диалог можно начать разговором, тему с предметами — картинками,
практикум — сразу заданием.
