# Тема 04 «Числа и возраст» · A0 — карта экранов

Цель темы: считать от 0 до 20, сказать и спросить возраст, продиктовать и записать номер телефона. Тема
показательная для аудирования: числа нужно узнавать на слух. У каждого задания на слух есть письменная
альтернатива «Нет возможности слушать» — число записано словами, нужно узнать его (та же цель — понять число;
урок засчитывается «без звука», навык «числа на слух» не подтверждается).

Навыки: `numbers` — числа 0–20 словом; `numbers_ear` — числа на слух; `tener_age` — возраст с tener;
`mi_tu_su` — мой, твой, его / ваш; `phone` — номер телефона; `accent_meaning` — tu / tú.

## Урок `numeros/telefono` — «Номер телефона»

- **Длина:** 21 шаг, 7 минут. **Новая лексика:** el número, el teléfono, ¿Cuál es...?, mi, tu, su.
  **Повторяется:** числа, возраст, ¿Cómo se llama usted?, más despacio.
- **Порядок:** «номер — девять цифр» → три слова → разговор в спортзале → вопросы к нему → mi / tu / su →
  выбор → номер на слух → миссия «Запись в языковую школу» → ответы администратору.
- **Самостоятельное воспроизведение:** номер цифрами, «Mi número es seis, cinco, cero». **Итоговая ситуация:** миссия.

## Урок `numeros/dictado` — «Диктант чисел»

- **Длина:** 6 шагов, 3 минуты. **Повторяется:** числа 0–20, номер телефона.
- **Порядок:** сразу диктант: пять чисел цифрами → номер телефона на слух.
- **Без звука:** «Нет возможности слушать» — те же числа словами (siete → 7); урок засчитывается «без звука».
  Без звука и без альтернативы урок не засчитывается (раньше засчитывался пустым на 100 %).
- **Убрано / объединено:** экран-инструкция «Послушайте и запишите… повторите урок через пару дней» убран —
  заголовок задания говорит то же самое.
