# Тема 02 «Me llamo… Знакомство» · A0 — карта экранов

Цель темы: представиться и спросить имя на «ты» и на «вы», ответить на знакомство (encantado / encantada,
mucho gusto, igualmente), сказать, кто есть кто, с глаголом ser. Показательная тема для начала урока с разговора.

Навыки: `me_llamo` — представиться и спросить имя; `encantado` — «очень приятно» и ответ; `ser_forms` — soy, eres,
es; `accent_meaning` — значок ´ меняет смысл (él / el, sí / si; введён в `start/vowels`); `tu_usted` — из темы 01.

## Урок `presentarse/vocab` — «Как тебя зовут?»

- **Длина:** 19 шагов, 6 минут. **Новая лексика:** me llamo…, ¿Cómo te llamas?, ¿Cómo se llama usted?,
  encantado/a, mucho gusto, igualmente. **Повторяется:** ¡Hola!, ¿Y tú?, perdón, señora, tú / usted.
- **Конструкции:** me llamo / te llamas / se llama (как готовые фразы); encantado — по тому, кто говорит.
- **Порядок (по примеру ТЗ):** короткий разговор знакомства → как спросить имя на «ты» и «вы» → выбор формы и
  ответ → ввод «меня зовут…» → «очень приятно»: encantado / encantada / mucho gusto, igualmente → ответ на
  знакомство → сборка → мини-миссия «Познакомьтесь на вечеринке» (ввод: имя + «очень приятно»).
- **Интерактив:** выбор, ответ на реплику, ввод, сборка. **Самостоятельное воспроизведение:** «Представьтесь»,
  итоговый ввод «Me llamo Pablo. Encantado». **Итоговая ситуация:** знакомство с Аной. **Проверяется:** форма
  вопроса (tú / usted), me llamo, род encantado.
- **Убрано / объединено:** без «Вспомним» и титульного экрана — урок открывается разговором; добавлена
  мини-миссия в конце (было: урок обрывался сборкой фразы); формат ввода — «меня зовут… по-испански».

## Урок `presentarse/grammar` — «Я, ты, он, она: глагол ser»

- **Длина:** 21 шаг, 7 минут. **Новая лексика:** yo, él, ella, ser, llamarse, ¿Quién es? **Повторяется:** me llamo,
  tú, usted, señor, sí / si.
- **Конструкции:** ser — soy / eres / es; él (он) и el (артикль); llamarse — me / te / se llamo; ¿Quién es? — Es…
- **Порядок:** примеры «Yo soy Ana…» (заметить: глагол есть всегда) → yo, él, ella, ser → правило и таблица →
  ввод форм → él / el → выбор → llamarse и ¿Quién es? → таблица (свёрнуто: две фамилии, почему без yo) → выбор.
- **Интерактив:** ввод формы, выбор. **Самостоятельное воспроизведение:** ввод soy / eres / es.
  **Проверяется:** форма ser по лицу, él / el, me / te / se.
- **Убрано / объединено:** без изменений по составу; навыки и ссылки на правило у каждого задания.

## Урок `presentarse/dialogue` — «На вечеринке»

- **Длина:** 11 шагов, 4–5 минут. **Новая лексика:** нет. **Повторяется:** вся тема, ¿Qué tal?, señor, buenas noches.

  «Новая соседка» → ответы соседке → сборка вежливого вопроса.
- **Интерактив:** вопросы к разговорам, ответ на реплику, сборка. **Итоговая ситуация:** миссия.
  **Проверяется:** понимание разговоров, выбор реплики в знакомстве.

## Урок `presentarse/listening` — «Кто есть кто?»

- **Длина:** 7 шагов, 4 минуты. **Новая лексика:** нет. **Повторяется:** вся тема.
- **Порядок:** слушаем скрытый разговор на уроке испанского → пары «кто есть кто» → четыре вопроса к нему.
- **Интерактив:** аудирование, пары, вопросы. **Проверяется:** понимание на слух. **Без звука:** «Нет возможности
  слушать» открывает текст разговора — урок засчитывается «без звука», аудирование не подтверждено.
- **Убрано / объединено:** пары и вопросы теста привязаны к разговору (`class`): в задании — «Слушать ещё раз»,
  текст до ответа — только как подсказка; вступление больше не советует «открыть текст».
