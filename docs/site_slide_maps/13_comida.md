# Тема 13 «Еда и напитки» · A1 — карта экранов

Цель темы: назвать продукты и напитки, спрягать глаголы на -er и -ir, рассказать о завтраке, обеде и ужине,
заказать в кафе и попросить счёт.

Навыки: `food` — продукты, напитки, приёмы пищи; `present_er_ir` — глаголы на -er / -ir; `bueno_bien` — bueno или
bien; `order_food` — para mí, quiero, la cuenta.

## Урок `comida/bebidas` — «Напитки»

- **Длина:** 15 шагов, 5 минут. **Новая лексика:** el agua, el té, la leche, el zumo, el refresco, el café con leche.

  jugo) → пары → на слух → ввод.
- **Убрано / объединено:** заметка про jugo стояла до слова zumo — перенесена к нему; ввод «чай с молоком», «апельсиновый

## Урок `comida/bar` — «En el bar»

- **Длина:** 18 шагов, 7 минут. **Новая лексика:** querer, tomar, para mí, algo, el bocadillo, la cuenta, ¿Cuánto es?,
  el euro.
- **Порядок:** четыре слова → «что ответить официанту?» → четыре слова → разговор в баре (вступление «готовый сценарий»,
  свёрнуто: Aquí tiene) → вопросы → миссия «Завтрак в баре» → реплика, ввод, сборка → на слух «Son siete euros».
- **Убрано / объединено:** строка «этот диалог — готовый сценарий» стояла отдельным экраном до слов — теперь на экране
  разговора; вопросы привязаны к разговору (`bar`) и миссии (`breakfast`); цена на слух — самостоятельное задание с
