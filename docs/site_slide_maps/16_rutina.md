# Тема 16 «Мой день» · A1 — карта экранов

Цель темы: рассказать о распорядке дня, спрягать возвратные глаголы и глаголы с чередованием в корне, связать рассказ
словами «сначала, потом, иногда». В конце — «Повторение» тем 13–16 с интервальным повторением навыков.

Навыки: `daily_routine` — me levanto, salgo de casa; `reflexive` — me, te, se, nos, os; `stem_change` — quiero, puedo,
pido; `sequence` — primero, luego, antes de, a veces, nunca.

  poder (`o → ue`) → ввод → pedir → pedir (`e → i`), правило «сапожка» (свёрнуто: где вы такое видели) → выбор.

## Урок `rutina/orden` — «Сначала, потом, иногда»

- **Длина:** 19 шагов, 7 минут. **Новая лексика:** temprano, luego, después, más tarde, antes de, después de, a veces,
  nunca.
- **Порядок (три витка):** «чтобы рассказ звучал связно; primero вы знаете» → четыре слова → выбор → antes de, después
  de → после них — инфинитив → выбор → a veces, nunca → nunca без no → выбор → ввод.
- **Убрано / объединено:** más tarde проверялся только автодобавкой — теперь ввод «Сегодня я ужинаю позже»; ввод
