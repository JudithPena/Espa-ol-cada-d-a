# Тема 00 «Старт» · A0 — карта экранов

Цель темы: читать испанские слова по правилам, слышать разницу букв и ставить ударение. Тема фонетическая:
главный материал — звук и буква, поэтому почти каждое задание на слух. Без звука у каждого такого задания
есть письменная альтернатива с русской транскрипцией (та же цель — связать звук и букву), урок засчитывается
«без звука». Вводный урок канала `start/intro` («как устроен канал») на сайте не показывается.

Навыки (`content/site/skills.yaml`): `stress` — ударение по правилам; `spell_hjg` — буквы h, j, g, gu, qu;
`spell_ll_n` — ll и ñ; `spell_czr` — c, z, ch, r/rr, v/b.

## Урок `start/vowels` — «Гласные и ударение»

- **Длина:** 23 шага, 6–7 минут. **Новая лексика:** ¡Hola! (карточка из вводного урока канала, первым шагом
  курса), la casa, el taxi, sí, no, el café, el hotel, la música.
- **Конструкции:** пять чётких гласных; три правила ударения; значок ´ (sí / si); артикли el / la как часть слова.
- **Порядок:** «слова читаются как пишутся» → гласные → первая порция слов → почему перед словами el / la →
  слышим чёткие гласные → правила ударения → слова со значком ´ → ударение на новых словах → sí / si → пары →
  диктант → два слова, которых ещё не было.
- **Интерактив:** выбор на слух, выбор ударения, пары, ввод по слуху. **Самостоятельное воспроизведение:**
  диктант la casa, la música. **Итоговая ситуация:** нет (урок правил чтения), в конце — перенос правил на новые
  слова Isabel, Pablo. **Проверяется:** чёткие гласные, правило ударения, значок ´.
- **Убрано / объединено:** тест урока повторял «Где ударение в hotel?» из задания — заменён новыми словами;
  заметка про артикли перенесена с экрана sí / si (другая мысль) сразу после первой порции слов, где el / la
  впервые видны; два вводных абзаца — один экран «как читаются гласные».

## Урок `start/consonants1` — «Согласные: h, j, g, qu, ll, ñ»

- **Длина:** 23 шага, 6–7 минут. **Новая лексика:** el jamón, el queso, la guitarra, la paella, la tortilla,
  España, mañana. **Повторяется:** hola, hotel (в таблице), гласные и ударение (jamón, España).
- **Конструкции:** h не читается; j и g + e/i = «х»; gu/qu + e/i = «г»/«к»; ll = «й»; ñ = «нь».
- **Порядок:** три витка «таблица с одной группой букв → 1–2 слова → задание на эту группу» (h/j/g → gu/qu →
  ll/ñ), затем пары и диктант.
- **Интерактив:** выбор (буква и звук), выбор написания на слух, пары, диктант. **Самостоятельное
  воспроизведение:** диктант mañana, el jamón. **Проверяется:** выбор буквы по звуку.
- **Убрано / объединено:** тест урока повторял задание «Какая буква никогда не читается?» — заменён вопросом
  про u в queso; la paella нигде не проверялась — добавлено задание на ll.
