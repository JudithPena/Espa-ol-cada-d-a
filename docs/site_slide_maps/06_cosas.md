# Тема 06 «Вещи вокруг нас» · A0 — карта экранов

Цель темы: назвать предметы вокруг себя, выбрать артикль по роду (el, la, un, una), образовать множественное
число и сказать, что где есть (hay). Пилот коротких грамматических циклов: «одно правило → 1–3 задания →
следующее правило».

Навыки: `que_es_esto` — «¿Qué es esto? — Es un…»; `gender` — род и артикль el / la, un / una; `el_vs_un` — новый
или уже известный предмет; `plural` — множественное число; `hay` — что где есть; `ser_forms` — es / son.

## Урок `cosas/genero` — «Мужской и женский род: el, la, un, una»

- **Длина:** 25 шагов, 8 минут. **Новая лексика:** la mesa, la silla, el día, el mapa, la foto, o.
- **Конструкции:** -o → el / un, -a → la / una; другие окончания — запоминать; исключения día, mapa, foto;
  un — новый предмет, el — уже известный.
- **Порядок (циклы):** вопрос «угадать по окончанию?» → mesa, silla → правило -o / -a → сортировка → «другие
