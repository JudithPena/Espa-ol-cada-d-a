Разделение данных сайта по уровням (`espanol/site_assets.py`) уже было в основной ветке: файл уровня A2
появляется сам, страница-оболочка остаётся меньше 1,5 МБ.

**Не сделано из дорожной карты (сознательно, чтобы не задерживать содержание):** синхронизация и размер записи
прогресса (P2, P3 — запись прогресса после A2 превысит порог отправки при закрытии страницы, останется отправка раз
в 5 минут), профиль ученика (P9 — задания «о себе» сделаны письмом по признакам, без хранения личных данных),
экран источника на весь экран (P6), блок `order` (P10), кнопка «Мой ответ тоже верный?» (P12), диагностика на входе.

## Договорённости по содержанию A2

1. **Тема = 7–9 уроков:** аудирование или диалог-вход → 2–4 урока грамматики и лексики → чтение с письмом → практика
   с миссией (разговор по шагам) → тест темы (`check: soft`, 10–12 пунктов, треть — ввод, не меньше двух на слух).
2. **В каждом уроке:** не больше 8 новых слов; не меньше двух пунктов ввода или сборки; хотя бы один пункт на слух
   (`say` + `noaudio`); одно задание «о себе» (`compose`) там, где есть что сказать о себе.
3. **Вопросы к источнику** отвечаются по репликам и тексту, а не по подписи говорящего или вступлению; в пояснении —
   цитата. Вопросы к тексту — по-испански.
4. **Неверные варианты** — из той же речевой функции или та же конструкция с типичной ошибкой; без «De nada» на всё.
5. **Ввод фразы** — шаблоном: местоимение, порядок слов, краткий ответ; к типичной ошибке — `mistakes`.
6. **Лексика возвращается:** слова прошлых тем A2 нарочно ставятся в тексты и задания следующих; блок `review`
   в уроках практики.
7. **Испанский — нормы Испании** (vosotros, pretérito perfecto для «сегодня», `vale`, `móvil`); спорное сверяется с RAE.
   Носителем тексты не вычитаны — это помечается в отчётах.
8. **Персонажи A2:** Irina (украинка, Мадрид), Diego (мексиканец, Мадрид), Olga (Валенсия, больница), Tom (англичанин,
   студент), Li (Китай, повар) и персонажи A0–A1 (Lucía, Pablo, Ana, Carlos, Elena…). Новый персонаж — в `course.yaml`
   (`names` / `roles`) и в `CAST` (`espanol/site_audio.py`).
9. **Контрольные точки:** КТ-1 (после темы 29) и КТ-2 (после темы 35) — `check: soft`; итог A2 — `check: control`.
10. **id темы** — латиница и `_`, без цифр; номера тем продолжают A1 (24…42).

## Цикл одной темы

1. Тема карты → список уроков, слова, конструкции, навыки (в `content/site/skills.yaml`).
2. YAML → `python -m espanol validate` (ошибок и предупреждений нет).
3. `python tools/site_ids_snapshot.py` → `node tools/site_map_gen.cjs --unit N --write`.
4. `python -m pytest -q tests/test_site_a2.py tests/test_scenario.py tests/test_site.py` и
   `node --test tests/site_course.test.cjs`.
5. `python -m espanol site --preview` → `node tools/site_walk.mjs --unit N` (и с `--mistakes`, `--noaudio`).
6. Строка в таблице статуса, коммит, пуш. Перед большим коммитом — полный `python -m pytest -q`.
