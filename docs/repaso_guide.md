# Карточки слов курса для повторения в боте

У каждого слова из уроков есть карточка. Бот показывает её в повторении `/repaso` и по ссылке
«🔁 Повторить слова урока» всем ученикам. Занятие устроено так же, как в «Моих словах»
(`docs/mis_palabras_guide.md`):

1. **Новые слова** — сначала озвучка, потом карточка и кнопка «➡️ Дальше».
2. **Повторение** — слово с озвучкой и 4 варианта перевода (`CHOICES`). Варианты берутся из слов
   уже вышедших уроков, переводы с общим значением рядом не ставятся. Бот сам видит, верно ли ответил
   ученик. Если ученик ошибся, бот показывает правильный ответ и что значил выбранный вариант, потом кнопку
   «Дальше». Если вариантов меньше двух (в самом начале курса), вместо них кнопки «Показать» и «Помню» / «Не помню».
3. **В конце** — проверка сегодняшних новых слов тем же выбором перевода.

За одно занятие — до 10 слов: те, что пора повторить, и до 5 новых. По ссылке из урока сначала идут слова
этого урока. Интервалы — 1, 3, 7, 14, 30, 60, 120 дней (`bot/src/srs.js`), код занятия — `bot/src/deck.js`.

## Откуда берётся карточка

- **Короткий разбор** — `content/repaso/NN_тема.yaml`, по файлу на тему курса. Его пишет Claude.
- **Если разбора ещё нет**, карточка собирается из урока: эмодзи, слово, чтение, перевод и пример из урока.
  Поэтому новые уроки работают в боте сразу, а разборы можно дописывать позже.

```yaml
words:
  - es: la casa                 # слово ровно как в уроке (поле es, без [чтения])
    pron: "…"                   # особенности чтения — только если они есть
    meaning: "Дом, жилище. …"   # что значит и когда говорят, 1–2 предложения
    examples:                   # 1–3, «пример — перевод»
      - "Es mi casa. — Это мой дом."
    collocations:               # необязательно, 2–4 «сочетание — перевод»
      - "en casa — дома"
    trap: "…"                   # необязательно: с чем путают, какую ошибку делают
```

Карточка в том виде, в каком её покажет бот: `python -m espanol carta "la casa"`.
Сколько слов уже с разбором, по темам: `python -m espanol carta`.

## Правила

- Курс — с нуля до A1, поэтому разбор **короткий**: без этимологии, синонимов, регистра и уровня CEFR.
- **В примерах — только слова, пройденные к уроку этого слова** (как во всём курсе); `validate` это проверяет.
  Имена из курса можно. Сочетания и ловушку `validate` не проверяет, но и там берите простые слова с переводом.
- Объяснения — полными предложениями, как в уроках (`docs/style_guide.md`).
- `pron` — только если чтение неочевидно: ударение, h не читается, ll/y, c/z, j/g, rr, мягкие b/d/g.
  Чтение русскими буквами бот берёт из урока.
- Испанский Испании; отличия Латинской Америки — с пометкой 🌎. Без флага 🇷🇺.
- Не меняйте `es` у слов в уроках ради карточек: по написанию слова бот помнит прогресс учеников.
