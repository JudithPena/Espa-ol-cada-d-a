# Español cada día — заметки для Claude

Telegram-курс испанского с нуля до A1: канал **@espanol_cada_dia**, бот **@Eduardo_maestro_bot**.
Как устроен проект, формат уроков и команды — в `README.md`. Общаемся с автором по-русски.

## Безопасность

- Токен бота хранится только в GitHub Secrets (`TELEGRAM_BOT_TOKEN`) и, при локальном запуске, в `.env`
  (он в `.gitignore`). Никогда не просите прислать токен в чат или на скриншоте, не записывайте его в файлы
  репозитория и не повторяйте его, даже если автор пришлёт его сам: тогда посоветуйте отозвать его через
  @BotFather (`/revoke`) и вписать новый в Secrets.

## Как публикуется

- Публикует GitHub Actions: `.github/workflows/publish.yml`, лимит `POSTS_PER_DAY` = 2. Запускает его
  бот на Cloudflare в 9:00 и 15:00 по Киеву (см. ниже). В `publish.yml` остался только запасной `cron`
  `0 15 * * *` (UTC, поздно вечером): он выпускает урок, только если бот не выпустил. Ранних `cron` туда
  не ставьте: GitHub опаздывает на 5–9 часов и выпустит урок раньше бота (так 24 октября урок 25 вышел в 10:55).
- Ветка `ccr-f4c9bfd6-txio5n` — единственная и ветка по умолчанию; расписание работает только в ней.
- После каждой публикации workflow сам коммитит `state/state.json` («Прогресс публикации»). Поэтому
  **перед любой работой делайте `git pull`**, а `state/state.json` руками не меняйте.
- Посты-статьи (Rich Messages, `espanol/rich.py`, картинки — `espanol/cards.py`) автору понравились.
  Какие уроки уходят в канал статьёй, задаёт `rich_posts` в `content/course.yaml` (список id или `all`);
  с 16 октября там `all`: все уроки начиная с 8-го выходят статьями. Workflow «Тест урока в личку» (`test-send.yml`)
  шлёт урок тому, кто последним написал боту, не в канал.
- **Бот на Cloudflare** (`bot/`, инструкция — `docs/bot_guide.md`, выкладывает workflow «Бот на Cloudflare»):
  в часы `PUBLISH_HOURS` по Киеву (`bot/wrangler.toml`, сейчас 9 и 15) запускает «Публикацию урока»
  через GitHub API — точно в срок; в личке ведёт повторения `/repaso` (у каждого ученика своё расписание в KV,
  только слова вышедших уроков). В конце каждого урока — ссылка «🔁 Повторить слова урока» на бота
  (`bot` в `content/course.yaml`): сначала слова урока, потом прошлые слова, которые пора повторить.
  По средам и субботам в 19:00 бот сам предлагает в личке повторить слова (`REMIND_DAYS`, `REMIND_HOUR`). Пока автор не настроил ключи Cloudflare в Secrets, workflow ничего не делает,
  а уроки выходят по старому `cron`. Когда бот работает, getUpdates недоступен: `--chat auto` шлёт
  в `TELEGRAM_REVIEW_CHAT_ID` (номер чата бот присылает на `/id`).
- Что опубликовано и что следующее: `python -m espanol status`. Ручной запуск — Actions → «Публикация урока»
  → Run workflow; ручные посты тоже считаются в дневной лимит.

## Разборы видео

- Отдельная рубрика, не уроки курса: `content/videos/NN_имя.yaml`, код — `espanol/videos.py`,
  все правила — `docs/video_guide.md`. Разборы опираются на курс, курс под них не меняем.
- `after` — последний вышедший урок на момент разбора (№1 — после урока 13). Слова из уроков 0…`after`
  не разбираем, все остальные слова из видео разбираем. Слова из прошлых разборов заново не разбираем и
  карточек к ним не делаем: бот сам ставит их списком «🔁 Слова из прошлых разборов». Номера уроков курса («подробнее в уроке N»)
  в разборах не пишем — автору такой формат не понравился.
- В посте: ссылка на видео и полный текст видео **построчно** (`segments`): под каждой фразой в оригинале —
  её новые слова, пояснение и перевод этой фразы под спойлером; текст делим на 10 смысловых блоков примерно равной длины. Без таймкодов и без вопросов
  «откройте минуту X». С №4 после текста — раздел «📚 Грамматика из видео» (2–3 темы из видео, блоки `header`,
  `rule`, `table` перед заданиями). В №1 «Новая рубрика», дальше — «Вторая часть рубрики» и т. д. «Как смотреть» — только «сначала видео, потом разбор» и совет смотреть с испанскими субтитрами. С обложкой, но без уровня и «после урока N» в шапке и на обложке; раскрывающиеся блоки — только переводы фраз и вопросы в заданиях
  (заголовки заданий видны). У перевода нет флага 🇷🇺: автор из Украины.
- Сначала в личку на проверку (`video:N` в «Тест урока в личку» или workflow «Разбор видео» → личка),
  в канал — только после «можно» от автора (workflow «Разбор видео» → канал). Если автор просит выпустить разбор
  в определённое время — `publish_at: "ГГГГ-ММ-ДД ЧЧ:00"` (по Киеву) в YAML: в этот час бот на Cloudflare сам
  запустит «Разбор видео» → канал (см. `docs/video_guide.md`).

## «Мои слова» (личная колода автора в боте)

- Не курс и не канал: автор присылает список слов (испанских или английских), Claude пишет к каждому
  карточку-разбор в `content/mis_palabras/NN_имя.yaml` — новым файлом с большим номером, по порядку.
  Формат и правила разбора (по промпту автора, но короче) — `docs/mis_palabras_guide.md`, образец —
  `tests/data/mis_palabras/01_ejemplo.yaml`. Слова колоды не обязаны быть из курса.
- Бот (`bot/src/deck.js`, `/palabras`, только чат `TELEGRAM_REVIEW_CHAT_ID`) каждый день в 8:00 и 19:00 (две смены) даёт по 10 новых
  и повторение по интервалам 1, 3, 7, 14, 30, 60, 120 дней. `word` у показанных карточек не меняйте:
  по хешу написания бот помнит прогресс (для исправлений — поле `id`).
- У Гали своя колода испанских слов в том же боте: `content/mis_palabras/galya/NN_имя.yaml` (формат тот же, слова
  автора она не видит), чат — секрет `GALYA_CHAT_ID`; кнопки колоды Гали начинаются с `w`, автора — с `p`.
- Проверка — тот же `python -m espanol validate`, карточка — `python -m espanol palabras слово`.

## Карточки слов курса (/repaso)

- У каждого слова из уроков в боте есть карточка: новое слово ученик сначала видит карточкой, потом выбирает
  перевод из вариантов (занятие то же, что в «Моих словах»). Короткий разбор — `content/repaso/NN_тема.yaml`,
  правила — `docs/repaso_guide.md`; без разбора карточка собирается из урока. В примерах — только слова,
  пройденные к уроку этого слова. Проверка — `python -m espanol validate`, карточка — `python -m espanol carta слово`.
- Новые уроки: когда добавляете слова в урок, допишите им разборы в `content/repaso/`.

## Правила контента

- Только пройденные слова: после любых правок `python -m espanol validate` должен писать «✅ Ошибок нет».
- Объяснения — полными предложениями («если… то», «чтобы», «потому что»), к каждому пункту правила
  свои примеры. Подробно — `docs/style_guide.md`.
- Номера уроков начинаются с 0 (вводный урок — №0). `id` уже опубликованных уроков не меняйте:
  по ним бот помнит прогресс.
- Уроки 0–1 вышли в канал до правки стиля и нумерации; вышедшие посты меняются только вручную
  в Telegram. В аудио урока 1 осталось название «Урок 2» — его там не исправить.
